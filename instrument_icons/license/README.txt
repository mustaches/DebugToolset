数字波形分析工具栏图标包
========================

来源与许可：
- icons/svg/tabler/*  来自 Tabler Icons (https://tabler.io/icons)，MIT License
- icons/svg/lucide/*  来自 Lucide (https://lucide.dev)，ISC License
- icons/svg/custom/*  (oscilloscope, logic-analyzer, eye-diagram) 为本项目原创，可自由使用

目录结构：
- svg/tabler, svg/lucide, svg/custom : 原始 SVG 源文件
- png/light/*_{16,24,32,48,256}.png  : 白色线条版（适合深色工具栏），透明背景
- png/dark/*_{16,24,32,48,256}.png   : 深色线条版（适合浅色工具栏），透明背景
- ico/*_light.ico, *_dark.ico        : ICO 文件，内含 16/24/32/48/64/128/256 多尺寸

建议：浅色工具栏用 dark 版，深色工具栏用 light 版。
