# ISP Studio Process 节点使用说明

本文档介绍 ISP Studio（`lib/modules/isp_studio/`）中全部 32 个 Process 类节点的功能、算法原理、参数含义与使用注意事项，包括：

- **主链 16 个**：RAW 域 8 个（黑电平校正 → 去马赛克）+ RGB 域 8 个（白平衡 → RGB→YUV 转换；其中高频边缘提取 edge_extract 支持 RGB/YUV/HSL 三域输入输出）；
- **色彩空间转换 5 个**：RGB / YUV / HSL 之间的互转（csc_rgb2hsl / csc_yuv2rgb / csc_yuv2hsl / csc_hsl2rgb / csc_hsl2yuv）；
- **Process → Fluorescence 子分组 6 个**：ICG 荧光 mono 域算子与融合；
- **调节器 5 个**：sat_bright_adjuster 色饱和度/亮度调节器（3.15）、bright_contrast_adjuster 亮度/对比度调节器（3.16）、levels_curves 曲线调节器（3.17）、color_balance 色彩平衡（3.18）、color_temp_adjuster 色温调节器（3.19）；HSL/RGB/YUV 调节器为同类的单域交互调参节点，本文不展开。

这些节点源自"双传感器并行 ICG 荧光内窥镜 ISP"在研方案（方案文档模块编号 W01–W36 / N01–N40 / R01–R15，见 `IspFlow/双传感器并行ICG荧光内窥镜ISP的FPGA实现方案.pdf`），本文各节点标注的编号以代码注释为准。

**实现依据**（本文所有公式、默认值、范围均以以下代码为准）：

- 算法核：`lib/modules/isp_studio/pipeline/isp_kernels.dart`（顶层纯 Dart 函数）；
- 节点端口/参数声明：`lib/modules/isp_studio/models/isp_node.dart` 的 `IspNodeRegistry.types`；
- 执行行为：`lib/modules/isp_studio/pipeline/pipeline_runner.dart`（`compileChain` / `runChainFrame`）。

## 1. 流水线顺序与数据格式

### 1.1 链内数据格式

帧数据在链上以 `_Frame` 形式流动（`pipeline_runner.dart`），像素缓冲约定如下：

| 格式标识 | 含义 | 缓冲布局 |
| --- | --- | --- |
| `mosaic` | RAW 马赛克帧（Bayer 或 RCCB/RCCG/RCCC/RYYCy/RGB-IR 等非 Bayer CFA） | `Uint16List`，长度 `w*h`，行优先，每像素一个采样 |
| `mono` | 单通道灰度（`cis_mono` 源直出，荧光链中间格式） | `Uint16List`，长度 `w*h` |
| `rgb` | RGB 中间格式 | `Uint16List`，长度 `w*h*3`，R/G/B 逐像素交织 |
| `yuv` | YUV 中间格式（默认 BT.601 全范围，U/V 以 `maxValue/2` 为零点） | `Uint16List`，长度 `w*h*3`，Y/U/V 逐像素交织 |
| `hsl` | HSL 中间格式 | 同上 |

- 所有 16 位中间格式的满量程为 `maxValue = 2^bitDepth − 1`，由链首源节点的位深参数决定（如 10bit → 1023，12bit → 4095）。
- 预览/仪器汇点最终把中间格式经色调映射 LUT 转成 8 位 RGBA（见 1.4）。
- 视频源另有 8 位平面轨道（`yuv444p` 三平面 / `mono8` 单平面）的高速路径，与 Process 节点无关，本文不展开。

### 1.2 推荐连接顺序

左侧工具栏 **Process 分组的排列顺序就是推荐的主链连接顺序**（`node_palette.dart` 的 `_processTypeIds` / `_fluorescenceTypeIds`）：

```
白光主链（Bayer RAW 源）：
  CIS 源 → black_level → dpc → fpn → lsc → grgb_balance → bayer_dnr
        → highlight → demosaic → white_balance → ccm → rgb_dnr
        → sharpen → gamma → ahe → csc_rgb2yuv → 预览/输出

荧光支链（MONO 源）：
  cis_mono → black_level(in_mono) → dpc → fpn → lsc → bayer_dnr
        → fluoro_leak → fluoro_background → fluoro_normalize
        → fluoro_temporal → pseudo_color 或 fluoro_fusion → 预览
```

参考 `IspFlow/ICG荧光融合ISP流程.ispflow` 双源示例。顺序并非强制（图按拓扑序执行），但颠倒顺序通常物理意义不对（例如先 demosaic 再做 RAW 域校正会报错，先 gamma 再降噪则降噪结果不进预览，见 1.4）。

### 1.3 端口与互斥规则

- RAW 域算子（black_level/dpc/fpn/lsc/grgb_balance/bayer_dnr/highlight）带双输入 `in`(Bayer) / `in_mono`(Mono) 与双输出 `out` / `out_mono`。**`in` 与 `in_mono` 属于同一视频输入互斥组**（`IspNodeType.videoInputGroupPorts`）：接入一路后另一路在画布上置灰。输出与输入同格式直通。
- Bayer 输入时邻域按同相位（±2 步进）取样；mono 输入时按全像素（±1 步进）取样，同一核函数两种用法。
- 格式不匹配时执行器直接抛错（如"去马赛克需要 RAW 马赛克输入""伪彩映射需要 Mono 输入"）。
- `fluoro_fusion` 的 `in_fluoro` 端口**不在**互斥组内，可与 `in`（白光 RGB）同时接入，构成双源链。含融合节点的链允许最多 2 个源节点，且第二个源必须是 RAW 源（`compileChain` 强制）。

### 1.4 Gamma 是主链的出口

`runChainFrame` 执行到 `gamma` 节点时立即把当前 RGB 帧经色调映射 LUT 转成最终 8 位 RGBA 并记为链结果：

- **Gamma 之后的节点仍会执行，但其结果不进入预览/输出**——链末端直接采用 Gamma 节点的 RGBA（Gamma 不修改 16 位帧本身，后续节点仍在 Gamma 前的线性数据上计算，纯属浪费）。因此 `rgb_dnr`、`sharpen` 等必须放在 `gamma` **之前**才有效。
- **链中没有 Gamma 节点时**，链末端做默认色调映射：RAW 源（线性数据）按 gamma 2.2 编码；图片/视频源本身已是 sRGB 显示数据，按 gamma 1.0 直通（避免二次提亮发白）。
- 末端为 `yuv`/`hsl` 格式时，先转回 RGB 再做上述映射（YUV 用 BT.601 全范围逆变换，与 `csc_rgb2yuv` 选 bt709/limited 时的预览色差见该节点注意事项）。
- 末端为 `mosaic` 格式时（预览节点的 `in_raw` 输入直链接入 RAW 帧，`in_raw` 与 RGB/YUV/HSL/Mono 输入同属互斥组）：**不做去马赛克**，每个像素的值直接作为亮度出灰度图（`monoToRgba`，默认 gamma 2.2），用于检查马赛克原始数据。

## 2. 主链：RAW 域节点

RAW 域节点均为原地（in-place）修改 `w*h` 缓冲，输入输出同格式。

### 2.1 black_level 黑电平校正

**功能**：按 2x2 相位（R/Gr/Gb/B）分别扣除传感器黑电平偏移，截零不拉伸。荧光 mono 链的对应实现为方案模块 N01–N03（白光 Bayer 路径属方案最前段，代码未标注具体编号）。

**算法原理**（`applyBlackLevel`）：

1. 按 Bayer 排列解析 2x2 四个相位的偏移量：R 相位用 `r`，B 相位用 `b`；绿色相位中与 R 同行的（Gr）用 `gr`，与 B 同行的（Gb）用 `gb`；
2. 逐像素 `v' = v − offset`，`v' ≤ 0` 时钳为 0，否则四舍五入；
3. mono 输入时（`pipeline_runner` 分支）只用 `r` 作为全图统一偏移，`gr/gb/b` 无效；`r` 为 0 时整帧跳过；
4. 非 Bayer CFA（RCCB 等）输入时按 RGGB 相位近似施加（代码注释明确为近似）。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `r` / R 黑电平 | 0.0 | 0 ~ 4095 | R 相位的扣除量（码值）。调大：R 通道整体变暗，扣除超过真实黑电平时暗部 R 截零、暗部偏青。应从传感器 datasheet 或遮光帧均值取得。mono 链中这是唯一生效的参数。 |
| `gr` / Gr 黑电平 | 0.0 | 0 ~ 4095 | Gr 相位扣除量。与 `gb` 不一致会在去马赛克后产生迷宫/网格伪影——两者应分别按各自相位的遮光统计填写。 |
| `gb` / Gb 黑电平 | 0.0 | 0 ~ 4095 | Gb 相位扣除量，同上。 |
| `b` / B 黑电平 | 0.0 | 0 ~ 4095 | B 相位扣除量。调大：暗部偏黄。 |

**注意事项**：

- 扣除是"截零"而非"减后重拉伸"：黑电平占用的码值空间被直接丢弃，后续节点看到的满量程实际变为 `maxValue − offset`。
- 必须放在链首：dpc/fpn 等后续算子的阈值与统计都假定黑电平已移除。

### 2.2 dpc 坏点校正

**功能**：检测并替换与邻域显著离群的坏点/亮点（方案 W06/W07、N06–N09）。

**算法原理**（`applyDpc`）：

1. 取当前像素的 3x3 邻域：Bayer 输入按**同相位**（±2 步进，最多 8 个邻居），mono 输入按全像素 8 邻域；
2. 求邻域中位数 `med`，若 `|v − med| > threshold/100 × maxValue` 判为坏点；
3. 替换策略按模式：
   - `median`：直接用 `med` 替换；
   - `directional`：在水平、垂直、主对角、副对角 4 个方向上各取一对对称点（步进同上），选两点差 `|va − vb|` 最小（即梯度最小、最可能是真实边缘方向）的一对，以 `(va+vb+1)>>1` 替换；四方向都越界时回退为中位数。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围/选项 | 说明与调整效果 |
| --- | --- | --- | --- |
| `threshold` / 离群阈值% | 5.0 | 0 ~ 100 | 判定门限，满量程百分比。10bit 源默认 5% ≈ 51 码值。调小：更多像素被判坏点，过小会把纹理细节抹掉；调大：弱坏点漏检。噪点多的高增益场景适当调小，高对比纹理多的场景适当调大。 |
| `mode` / 模式 | median | median / directional | `median` 简单直接但会轻微模糊孤立细节；`directional` 沿最小梯度方向插值，斜边/纹理保持更好，代价是 4 次方向比较。边缘伪影敏感时用 directional。 |

**注意事项**：判定和替换都基于"同相位"邻域，不会跨颜色通道引入串扰；但必须位于黑电平校正之后，否则含偏移的暗部统计会干扰门限。

### 2.3 fpn FPN 校正

**功能**：估计并扣除行/列固定图案噪声（传感器读出电路的逐行/逐列偏移，方案 W08–W11、N10–N13）。

**算法原理**（`applyFpn`）——估计与施加分离，避免把图像内容当成 FPN：

1. **低通分离内容**（以行校正为例）：先对全图做垂直方向滑窗盒式均值（窗半径 `radius`，代码内固定为 8，见注意事项），得到低频图 `low`；残差 `res = 原图 − low` 中，竖条等列方向内容保留在低频里，逐行 FPN 进入残差；
2. **边缘掩膜**：垂直梯度超过 `2 × maxCorr` 的像素视为内容边缘，其邻域按 `radius` 做垂直膨胀后整段剔除，不参与统计（这些像素的低通被边缘污染）;
3. **稳健估计**：每行对未被掩膜的残差取**中位数**，即该行偏移；
4. **限幅扣除**：校正量限幅 `±maxCorr`，逐像素扣除后截零。

列校正同理（水平低通 + 水平梯度掩膜 + 列中位数）。行、列两轮依次进行。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `row` / 行校正 | true | 布尔 | 是否做行（水平条纹）校正。画面只有列条纹时可关掉行校正，避免行统计引入的微弱横带。 |
| `col` / 列校正 | true | 布尔 | 是否做列（竖直条纹）校正。两者都关则节点整体无操作。 |
| `maxCorr` / 最大校正量 | 64.0 | 0 ~ 4095 | 单像素最大扣除码值，同时决定边缘掩膜门限 `2×maxCorr`。调大：能校正更强的条纹，但门限随之升高，更多内容边缘参与统计、且有内容被误当 FPN 的风险；调小：强条纹校不干净。应按遮光帧实测的行/列偏移幅度设置。 |

**注意事项**：

- 核函数还有 `radius` 参数（低通窗/掩膜膨胀半径，默认 8），但**节点未暴露该参数**，界面上不可调，恒为 8。
- Bayer 输入时行/列统计不区分相位（`pattern` 在核内仅作文档化参数），因此对 Bayer 源它是"跨相位"的全局校正；相位间系统的行/列差异应交给 black_level/grgb_balance 处理。

### 2.4 lsc 镜头阴影校正

**功能**：补偿镜头渐晕/ shading——以可调中心为原点的径向二次增益曲面，边缘提亮（方案 W12–W14、N14–N16）。

**算法原理**（`applyLsc`）：

```
gain(x, y) = 1 + strength × (dx² + dy²) / rMax²
```

- `(dx, dy)` 为像素到中心 `(centerX×(w−1), centerY×(h−1))` 的偏移；
- `rMax` 为中心到**最远角**的距离，保证最远角处增益恰为 `1 + strength`；
- 结果截位到 `maxValue`；增益与相位无关，Bayer/mono 通用；`strength == 0` 时整帧跳过。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `strength` / 强度 | 0.5 | 0 ~ 2 | 边缘最大增益倍率。从 0 调到 1：边缘增益从 1.0 线性升到 `1 + 1×(r/rmax)²`，角落最多 +100%；调到 2 时角落 +200%。过大会使边缘高光截位饱和（边缘过曝、色块），且会连带放大边缘噪声与 FPN。应按平场（匀光源）实测的暗角比例设置。 |
| `centerX` / 中心 X | 0.5 | 0 ~ 1 | 光学中心归一化横坐标。镜头装配偏心时按实测偏移；偏离真实中心会让一侧边缘校正不足、另一侧过校正。 |
| `centerY` / 中心 Y | 0.5 | 0 ~ 1 | 同上，纵坐标。 |

**注意事项**：单曲面近似无法表达真实的逐颜色/逐格 shading 表，对严重渐晕只能做到"大体拉平"；它是增益放大，应放在 fpn/dpc 之后（否则噪声和坏点一起被放大）。

### 2.5 grgb_balance Gr/Gb 均衡

**功能**：收敛两个绿色相位（Gr 与 R 同行、Gb 与 B 同行）的全局均值差，消除去马赛克后的迷宫（maze）伪影（方案 W15）。

**算法原理**（`applyGrGbBalance`）：

1. 分别统计全图 Gr、Gb 像素的均值 `meanGr`、`meanGb`（任一为 0 或缺失则直通）；
2. 目标值 `target = (meanGr + meanGb) / 2`，两相位各自增益：

```
gainGr = 1 + (target/meanGr − 1) × strength
gainGb = 1 + (target/meanGb − 1) × strength
```

3. 逐像素乘增益，**截位到 65535**（核内硬编码，非 `maxValue`——见注意事项）。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `strength` / 强度 | 1.0 | 0 ~ 1 | 向中点收敛的比例。1.0 = 完全拉平两相位均值；0 = 不处理；中间值部分收敛。默认 1.0 即可，仅在画面本身存在真实的绿色相位差异（极少见，如特定光照下的双色温场景）时调小。 |

**注意事项**：

- 仅对 Bayer 马赛克输入有效；mono 输入或非 Bayer CFA（RCCB 等）输入时**直通**（无 Gr/Gb 相位概念）。
- 它是全局单增益校正，校正的是均值差异；若 Gr/Gb 差异随照度非线性变化，本节点无法完全消除。
- 核内截位常量写死 65535，对低位深源（10/12bit）等于不截位，与 lsc 等按 `maxValue` 截位的节点略有差异（实测无影响，属实现细节）。

### 2.6 bayer_dnr Bayer 降噪

**功能**：RAW 域保边降噪，在去马赛克之前抑制光子散粒噪声与读出噪声（方案 W16/W17、N24/N25）。

**算法原理**（`applyBayerDenoise`）：

同相位 3x3（mono 为全像素 3x3）加权平均，中心像素权重恒为 1，邻居权重：

```
σ = strength × √(I + 64)        （噪声模型 σ² = aI + b，取 a=1、b=64，I 为中心像素值）
w(Δ) = 1 / (1 + (Δ/σ)²)         （Δ = 邻居 − 中心）
```

`strength ≤ 0` 时整帧跳过。权重函数是 Lorentzian 型：亮度差远小于 σ 的邻居权重≈1（充分平滑），远大于 σ 的邻居权重→0（边缘保护）。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `strength` / 强度 | 1.0 | 0 ~ 4 | σ 的倍率。调大：更多邻居获得高权重，降噪更强、画面更糊，边缘保护门限同步放宽（弱边缘也会被抹平）；调小：降噪变弱。暗光高增益素材适当调大（噪声 σ 本来就随 √(I+64) 自适应）；锐利纹理场景调小。0 = 关闭。 |

**注意事项**：RAW 域降噪必须在 demosaic 之前——去马赛克后噪声已被插值扩散到邻像素，同相位假设不再成立（RGB 域降噪请用 `rgb_dnr`）。

### 2.7 highlight 高光恢复

**功能**：处理达到满量程的饱和像素——重建或软压缩，减轻高光溢出硬边（方案 W18/W19）。

**算法原理**（`applyHighlightRecovery`），膝点 `kneePt = knee × maxValue`：

- `recover`（默认）：值 ≥ kneePt 的像素视为饱和，用同相位 3x3（mono 为全像素）邻域中**未饱和**像素（< kneePt）的均值重建；邻域全部饱和时保持原值不动；
- `clip`：膝点以上做软压缩，平滑收敛到满量程：

```
d  = v − kneePt            （v > kneePt）
v' = kneePt + d × range / (range + d) ，range = maxValue − kneePt
```

即 `d → ∞` 时 `v' → maxValue`，膝点处导数连续，避免硬切产生的色块。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围/选项 | 说明与调整效果 |
| --- | --- | --- | --- |
| `mode` / 模式 | recover | recover / clip | `recover` 用邻域信息重建饱和区，能恢复部分高光层次，但大面积全饱和区（邻域无可用像素）无效；`clip` 不改写邻域、只压缩曲线，对单通道先饱和的彩色高光更稳。内窥镜冷光源直射金属反光场景可试 clip。 |
| `knee` / 膝点 | 0.9 | 0.5 ~ 1 | 饱和判定/软压缩起点（满量程比例）。默认 0.9 即最高 10% 码值参与处理。调小：更多高光被重建/压缩，恢复范围大但可能压掉本该保留的亮部层次；调大到 1.0：只有完全顶满 maxValue 的像素被处理。 |

**注意事项**：`recover` 模式工作在 RAW 域、按同相位取邻域，因此必须放在 demosaic 之前；它救不回"四相位全饱和"的死白区域。

## 3. 主链：RGB 域节点

### 3.1 demosaic 去马赛克

**功能**：把单采样点的马赛克帧插值为每像素三通道的 RGB 帧，是 RAW 域与 RGB 域的分界（代码未标注方案编号）。

**算法原理**：`algorithm` 参数选择 Bayer 插值算法（仅 Bayer CFA 生效），默认双线性插值（`demosaicBilinear`），规则：

- 本通道：保留真值；
- R/B 站点缺 G：上下左右 4 个轴向邻居平均；
- G 站点缺 R/B：该颜色的两个轴向邻居平均（横向或纵向，由相位决定）；
- R 站点缺 B（或反之）：4 个对角邻居平均；
- 边缘像素用现存邻居的通用平均；内部像素走预计算"取数计划"快速路径。

`bilinear` 之外的 5 种高级算法在 `demosaic_advanced.dart`（均为**简化实现**，忠实原论文核心思想，边界 2~3 像素环回退双线性）：

| 算法 | 出处 | 核心思想 | 特点/适用场景 |
| --- | --- | --- | --- |
| `mhc` | Malvar, He, Cutler, ICASSP 2004 | 梯度校正线性插值：G 用 5x5 FIR（含亮度梯度校正项），R/B 在 G 相位/对方相位各有固定卷积核 | 纯线性、无方向判断，**快**且明显优于双线性，边缘拉链少；通用首选 |
| `aahd` | Hirakawa & Parks, IEEE TIP 2005 | H/V 两方向各生成候选图（G 沿方向插值、色差平滑），转 CIELab 后按 3x3 邻域同质性投票选方向 | 边缘方向自适应，彩色边缘伪彩少；最慢（Lab 转换 + 双候选图） |
| `amaze` | Zhang & Wu, IEEE TIP 2005 | G 按方向梯度反比加权融合（简化为 H/V 两方向，原论文四方向），R/B 色差平滑 + 色差平面 3x3 中值滤波去拉链 | 细纹理/高频细节保留好，抗拉链 |
| `lmmse` | Zhang & Wu, IEEE TIP 2005 | G 沿 H/V 梯度校正估计，按 3x3 窗口亮度二阶差分能量逆加权融合（简化：省略方向分类与维纳权重推导、R/B 省略二阶 Laplacian 迭代校正） | 抗噪较好，噪声素材边缘平滑 |
| `igv` | Pekkucuksen & Altunbasak, ICIP 2010 | **等价思想实现**（参考 darktable/RawTherapee 思路）：MHC 式 5x5 得 G 初值，再按 H/V 窗口方差无阈值加权融合，R/B 色差平滑 | 无硬阈值，抗噪与边缘兼顾 |

非 Bayer CFA 源自动切换对应核（与 `algorithm` 无关）：RCCB（`G ≈ C − (R+B)/2`）、RCCG（`B ≈ C − R − G`）、RCCC（`G = B = (C−R)/2`）、RYYCy（`G = Y − R`，`B = Cy − G`）、RGB-IR（插值后按源节点的 IR 扣除比例扣 IR 分量）。这些是工程近似，非原厂算法。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 选项 | 说明 |
| --- | --- | --- | --- |
| `algorithm` / 算法 | bilinear | bilinear / mhc / aahd / amaze / lmmse / igv | Bayer 插值算法（按复杂度递增排列），仅 Bayer CFA 源生效；非 Bayer CFA 忽略此参数。未知取值执行时抛错。 |

**注意事项**：

- 输入必须是 `mosaic` 格式；`cis_mono` 源输出的是 mono，**不能**接入 demosaic（mono 链用荧光节点或直接预览）。
- 双线性是最简单的去马赛克，高对比细纹理处会有拉链/伪彩；在意画质用 `mhc`（快）或 `aahd`/`amaze`（更稳），噪声大的素材优先 `lmmse`/`igv`。所有 RAW 域校正（dpc/fpn/lsc/grgb/bayer_dnr/highlight）都应放在它之前。
- 5 种高级算法是教学/调试向简化实现：边界 2~3 像素环回退双线性，性能未优化（AAHD 含 Lab 转换，4K 帧明显变慢），不要当作生产级实现基准。

### 3.2 white_balance 白平衡

**功能**：调整 R/B 通道增益使中性物体呈中性色（代码未标注方案编号）。

**算法原理**：

- `auto`（默认）：灰世界法（`autoWhiteBalanceGains`）——每 16 像素抽一次样统计全图 R/G/B 均值，令 `rGain = meanG/meanR`、`bGain = meanG/meanB`（均值为 0 时对应增益取 1.0）；
- `manual`：直接使用 `rGain`/`bGain`；≤ 0 时按 1.0 处理；
- 施加（`applyWhiteBalance`）：每通道一张 `maxValue+1` 大小的 LUT，`v' = clamp(round(v × gain))`；两增益都为 1.0 时整帧跳过。G 通道不动。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围/选项 | 说明与调整效果 |
| --- | --- | --- | --- |
| `mode` / 模式 | auto | manual / auto | auto 每帧按画面内容重算增益；manual 锁定手动增益（多帧播放时画面色调不漂移，推荐使用已知光源的手动值）。 |
| `rGain` / R 增益 | 1.0 | 0.1 ~ 8 | manual 模式的 R 通道乘数。调大画面偏红；>1 时高端码值截位到 maxValue（高光溢出色块）。 |
| `bGain` / B 增益 | 1.0 | 0.1 ~ 8 | 同上，B 通道。 |

**注意事项**：灰世界假设"全图平均为灰色"，内窥镜画面大面积单一色调（如血红组织占满视野）时 auto 会把主色强行拉灰、产生严重色偏——这种场景必须切 manual。auto 模式按帧重算，视频播放时可能有轻微色温呼吸。

### 3.3 ccm 色彩校正 CCM

**功能**：3x3 色彩校正矩阵，把传感器光谱响应映射到目标色域（代码未标注方案编号）。

**算法原理**（`applyCcm`）：行优先 3x3 矩阵，2^20 定点整数乘法（64 位中间量，不溢出），结果四舍五入并截位到 `0..maxValue`：

```
[R']   [m0 m1 m2] [R]
[G'] = [m3 m4 m5]×[G]
[B']   [m6 m7 m8] [B]
```

单位矩阵（定点精确判定）时整帧跳过。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 说明 |
| --- | --- | --- |
| `matrix` / 3x3 矩阵 | 单位阵 | 9 个浮点数（行优先），UI 提供矩阵编辑器。通常由色彩标定（色卡 + 最小二乘拟合）得到；行和偏离 1 会改变整体亮度。对角线大于 1 提升对应通道饱和度，负的非对角项制造通道间串扰补偿。 |

**注意事项**：CCM 是线性操作，必须放在 gamma（非线性）之前；放在白平衡之后（先归一中性色，再做色域映射）。

### 3.4 rgb_dnr RGB 降噪

**功能**：RGB 域（YUV 空间）二次降噪——亮度保边平滑 + 色度低通（方案 W29–W31）。

**算法原理**（`applyRgbDenoise`）：

1. 全帧转 YUV（BT.601 全范围定点，`rgbToYuv`）；
2. **亮度 Y**：3x3 全像素保边加权平均，权重模型与 `bayer_dnr` 相同（`σ = luma × √(Y+64)`，邻居权重 `1/(1+(Δ/σ)²)`），`luma` 为倍率；
3. **色度 U/V**：3x3 盒式均值得到 `avg`，按 `chroma`（0..1）混合：`C' = C×(1−chroma) + avg×chroma`；
4. 转回 RGB（`yuvToRgb`）写回原缓冲。`luma ≤ 0` 且 `chroma ≤ 0` 时整帧跳过。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `luma` / 亮度强度 | 1.0 | 0 ~ 4 | 亮度 σ 倍率。调大：亮度噪声抹得更平，细节同步损失；0 = 亮度不处理（仅色度降噪）。人眼对色度噪声更敏感、对亮度细节更敏感，一般亮度强度低于色度。 |
| `chroma` / 色度强度 | 0.5 | 0 ~ 1 | 色度低通混合比。1 = U/V 完全替换为 3x3 盒式均值（强色斑抑制，彩色边缘轻微晕色）；0 = 色度不处理。 |

**注意事项**：

- 必须放在 **gamma 之前**（见 1.4：gamma 之后节点结果不进预览）。
- 与 bayer_dnr 是互补关系：RAW 域一档 + RGB 域一档，单档拉满都不如两档适度。
- 内部含 RGB→YUV→RGB 两次全帧转换，是链上较重的节点之一。

### 3.5 sharpen 锐化

**功能**：亮度 unsharp mask 锐化，增强边缘对比（方案 W32–W34）。

**算法原理**（`applySharpen`）：

1. 按 BT.601 系数提取亮度 `Y`（16 位定点）；
2. `detail = Y − 3x3盒式均值`；`|detail| < threshold` 视为噪声置零；
3. `Y' = clamp(Y + amount × detail, 0, maxValue)`，三通道按 `scale = Y'/Y` 等比缩放并截位（Y = 0 或 detail = 0 的像素不动）。

只动亮度比例、不动色调，因此锐化不产生色偏。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `amount` / 强度 | 0.5 | 0 ~ 4 | detail 的加成倍数。1.0 表示把 3x3 高频分量加倍；过大出现白边/黑边光晕（overshoot 被截位后更明显）。0 = 关闭。 |
| `threshold` / 噪声门限 | 4.0 | 0 ~ 256 | detail 的死区门限，单位是码值、量纲与数据位深一致（10bit 源 Y 范围 0..1023，默认 4 ≈ 0.4% 满量程）。调大：只有强边缘被锐化，避免噪声被放大；调小：弱纹理也锐化，画面颗粒感增强。高噪声素材应先降噪再锐化，并配合调大该门限。 |

**注意事项**：必须放在 gamma 之前（线性域操作 + 1.4 的出口规则）；顺序上建议 rgb_dnr → sharpen（先降噪后锐化，否则锐化放大噪声）。

### 3.6 edge_extract 高频边缘提取

**功能**：亮度高通滤波，输出黑底白线边缘图，用于观察画面高频细节/边缘分布。RGB/YUV/HSL 三域通用：输入端口 `in`(RGB)/`in_yuv`/`in_hsl`（互斥视频输入组，只接一路），输出端口 `out_rgb`/`out_yuv`/`out_hsl`（同格式三路输出）+ `out_mono`（单通道边缘亮度图 w*h，可直接接预览/仪器的 Mono 输入或乘法器等 mono 节点），帧格式不变。节点内嵌双联对比预览（左输入/右输出）+ 增益/门限两行滑块，默认宽度加倍（同 HSL 调节器）。

**算法原理**（`extractHighFreq`）：

1. 按输入色彩域取亮度通道：RGB 按 BT.601 系数提取亮度 `Y`（16 位定点，与 sharpen 同源），YUV 取 Y 通道，HSL 取 L 通道；
2. `detail = Y − 3x3盒式均值`，归一化为相对对比度 `rel = |detail| / 邻域均值`（均值下限 `maxValue/128` 防近黑除零爆增益）；`rel < threshold/maxValue` 视为噪声置零（**相对门限**，与归一化同口径，避免暗区/柔和小 detail 边缘被绝对门限整体吞掉）；
3. 输出 = `clamp(gain × √rel × maxValue)` 的黑底白线图：**√rel 显示压缩**让弱边缘显著提亮（rel=0.01 → 0.1×满量程）、强边缘饱和；平坦区为黑，边缘无论亮边暗边、暗区亮区均为同亮度亮线（RGB 域三通道同值，YUV 域 `U=V=中灰`，HSL 域 `H=0、S=0、L=v`）。

边界按可用邻域平均（同 sharpen）。本算子非恒等：始终输出新帧（增益 1 也不是直通）。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `gain` / 增益 | 1.0 | 0.1 ~ 8 | √rel → 满量程的放大倍数（rel=1 即边缘与邻域等幅反差时输出满量程）。调大：弱反差边缘也更亮；调小：只剩强反差边缘。 |
| `threshold` / 噪声门限 | 4.0 | 0 ~ 256 | 相对噪声门限：`rel < threshold/maxValue` 的边缘置零（码值量纲，按满量程折算）。调大：只保留强反差边缘、抑制噪声；调小：弱纹理也提取。 |

**注意事项**：必须放在 gamma 之前（线性域操作）。GPU 快路径已支持本节点（`shaders/isp/isp_edge_extract.frag`，三域同一 shader，与 CPU 逐值一致）。

### 3.7 gamma Gamma/色调

**功能**：16 位线性 RGB → 8 位 RGBA 的色调映射，同时提供 gamma、亮度、对比度调节（代码未标注方案编号）。

**算法原理**（`tonemapToRgba` + `_tonemapLut`）：每通道一张 `maxValue+1` 大小的 LUT，逐像素查表：

```
c = v / maxValue            （归一化）
c = c + brightness          （整体偏移）
c = (c − 0.5) × contrast + 0.5
c = clamp(c, 0, 1)
c = c ^ (1/gamma)           （幂次编码）
out = round(c × 255)        （alpha 恒 255）
```

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `gamma` / Gamma | 2.2 | 0.5 ~ 5 | 幂次编码指数。>1 时 `1/gamma < 1`，暗部被抬升（标准 sRGB 显示补偿）；调小（<1）画面压暗、暗部细节被吞。RAW 线性素材通常 2.2。≤0 按 2.2 处理。 |
| `brightness` / 亮度 | 0.0 | −0.5 ~ 0.5 | 归一化域的整体加减，先于对比度和 gamma。+0.1 即全图抬 10% 满量程，注意高光先被 clamp 截掉。 |
| `contrast` / 对比度 | 1.0 | 0.2 ~ 3 | 绕中点 0.5 的线性缩放。>1 拉开反差（两端截位增多），<1 压缩反差发灰。≤0 按 1.0 处理。 |

**注意事项**：

- **本节点是主链出口**：它产生最终 RGBA，之后的节点结果不进预览（1.4）。想对比"加/不加某节点"，应把该节点放在 gamma 之前切换，而不是拖动连线绕过 gamma。
- 无 gamma 节点的链末端会自动补默认映射（RAW 源 gamma 2.2），两个 gamma 节点串联只有最后一个生效（第二个直接对同一 16 位帧再出一张 RGBA，并非对 8 位结果二次处理）。

### 3.8 csc_rgb2yuv RGB→YUV 转换

**功能**：RGB 域转 YUV 域（视频编码/显示接口前的色彩空间转换，方案 W36）。

**算法原理**（`convertRgbToYuvCsc`）：16 位定点矩阵乘法，`standard=bt601` 且 `range=full` 时走 `rgbToYuv` 快速路径：

```
Y = 0.299R + 0.587G + 0.114B              （BT.601）
U = −0.168736R − 0.331264G + 0.5B  + half
V = 0.5R − 0.418688G − 0.081312B   + half   （half = maxValue/2）
```

BT.709 换用 `Y = 0.2126R + 0.7152G + 0.0722B` 等对应系数。`range=limited`（tv 范围）在全范围结果上再做标度压缩：

```
Y' = offY + Y × 219/255      （offY = maxValue×16/255，即 Y 落入 16..235 标度）
C' = half + (C−half) × 224/255            （C 落入 16..240 标度）
```

输出帧格式变为 `yuv`，供 yuv_splitter / 仪器 / 输出节点使用。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 选项 | 说明与调整效果 |
| --- | --- | --- | --- |
| `standard` / 标准 | bt601 | bt601 / bt709 | 转换系数集。bt709  greens 权重更高，与 bt601 的差异主要体现在绿色为主的画面亮度与色度坐标上。应与下游设备/编码器实际采用的标准一致，不一致会造成轻微色偏。 |
| `range` / 范围 | full | full / limited | full：Y/U/V 用满 `0..maxValue`；limited：压缩到 tv 标度（动态范围损失约 14%），对接要求 limited range 的编码器/显示器时使用。 |

**注意事项**：链末端预览把 yuv 转回 RGB 时**固定使用 BT.601 全范围逆变换**（`yuvToRgba`）。因此选 bt709 或 limited 后，预览画面会有轻微色差/对比变化——这不代表数据错误，YUV 分路器与按格式消费的下游拿到的仍是正确的 bt709/limited 数据。

### 3.9 csc_rgb2hsl RGB→HSL 转换

**功能**：RGB 域转 HSL 域（色调/饱和度/亮度分离，便于接 hsl_splitter 做独立通道处理）。

**算法原理**（`rgbToHsl`）：逐像素归一化到 0..1 后：

```
L = (max + min) / 2                     （max/min 为 R/G/B 最大、最小分量）
d = max − min
S = L > 0.5 ? d / (2 − max − min) : d / (max + min)     （d = 0 时 S = 0）
H 按最大分量所在扇区：R：(G−B)/d；G：(B−R)/d + 2；B：(R−G)/d + 4
```

H 按 0..360° 映射到 0..maxValue，S/L 映射到 0..maxValue。

**参数说明**：无参数。

**注意事项**：灰度像素（d = 0）的 H 固定为 0；链末端预览把 hsl 转回 RGB 用 `hslToRgba`（同一实现的逆变换），无色差。

### 3.10 csc_yuv2rgb YUV→RGB 转换

**功能**：YUV 域转回 RGB 域（`csc_rgb2yuv` 选 bt601/full 时的逆变换）。

**算法原理**（`yuvToRgb`）：BT.601 全范围逆变换，16 位定点整数移位加速，U/V 以 `maxValue/2` 为零点：

```
R = Y + 1.402·V'
G = Y − 0.344136·U' − 0.714136·V'       （U' = U − half，V' = V − half）
B = Y + 1.772·U'                        （half = maxValue/2）
```

结果钳位到 0..maxValue。

**参数说明**：无参数。

**注意事项**：对 bt709/limited 来源的 YUV 数据请先确认系数匹配——本核固定 BT.601 全范围，与 `csc_rgb2yuv` 的 bt601/full 路径严格互逆（往返误差 ≤2 码值，8 位量级）。

### 3.11 csc_yuv2hsl YUV→HSL 转换

**功能**：YUV 域直接转 HSL 域，省去手工串两个转换节点。

**算法原理**（`yuvToHsl`）：单遍融合实现——循环内先按 `yuvToRgb` 的定点公式（BT.601 全范围逆变换）算出 RGB 中间值，再直接按 `rgbToHsl` 的逻辑求 H/S/L，不分配中间缓冲；数学上等价于 YUV→RGB→HSL，数值结果与 `yuvToRgb` + `rgbToHsl` 两段中转逐点一致，码值口径与 3.8/3.9 完全一致。

**参数说明**：无参数。

**注意事项**：精度上等价于 `csc_yuv2rgb` + `csc_rgb2hsl` 串联；融合实现省去了中间 RGB 帧的分配与第二遍遍历。

### 3.12 csc_hsl2rgb HSL→RGB 转换

**功能**：HSL 域转回 RGB 域（`rgbToHsl` 的逆变换）。

**算法原理**（`hslToRgb`）：H/S/L 按 0..maxValue 归一化后：

```
S = 0 时：R = G = B = L                 （灰度）
否则：Q = L < 0.5 ? L·(1+S) : L + S − L·S，P = 2L − Q
R = hueToRgb(P, Q, H + 1/3)；G = hueToRgb(P, Q, H)；B = hueToRgb(P, Q, H − 1/3)
```

**参数说明**：无参数。

**注意事项**：H 按模 360° 处理（越界回绕）；与 `csc_rgb2hsl` 串联的往返误差 ≤2 码值（8 位量级）。

### 3.13 csc_hsl2yuv HSL→YUV 转换

**功能**：HSL 域直接转 YUV 域，供 yuv_splitter / 仪器 / 输出节点使用。

**算法原理**（`hslToYuv`）：单遍融合实现——循环内先按 `hslToRgb` 的逻辑（逆变换）算出 RGB 中间值，再直接按 `rgbToYuv` 的定点公式（BT.601 全范围矩阵）求 Y/U/V，不分配中间缓冲；数学上等价于 HSL→RGB→YUV，数值结果与 `hslToRgb` + `rgbToYuv` 两段中转逐点一致。

**参数说明**：无参数。

**注意事项**：与 `csc_hsl2rgb` + `csc_rgb2yuv`（bt601/full）串联等价；链末端预览对 yuv 的逆变换见 3.7 注意事项。

### 3.14 ahe 自适应直方图均衡

**功能**：CLAHE（对比度受限的自适应直方图均衡）。对亮度做分块自适应均衡，增强局部对比度（暗部/高光细节拉开），三通道按亮度比例等比缩放，不改变色调与饱和度。支持 **RGB（`in`/`out`）与 Mono（`in_mono`/`out_mono`）双通路**：Mono 通路用于单通道视频信号（如荧光 Mono 链），单通道帧直接作为亮度平面均衡，无需亮度提取与色度缩放；`in` 与 `in_mono` 属视频输入互斥组，只能接入一路，输出与输入同格式。

**算法原理**（`applyClahe`）：

1. 逐像素求亮度 `Y`（BT.601 定点加权和，与 sharpen 一致）；
2. 把图像分成 `blockSize × blockSize` 的 tile，逐 tile 统计 256 bin 亮度直方图；
3. 直方图按 `clipLimit`（tile 内平均计数的倍数）裁剪，超出部分均匀再分配到全部 bin，再求累积分布（CDF）得到该 tile 的均衡 LUT——裁剪是 CLAHE 与普通 AHE 的区别，防止平坦区噪声被过度放大；
4. 每像素的均衡亮度由周围 4 个 tile 中心的 LUT 双线性插值得到（标准 CLAHE 做法，避免块效应）；
5. 三通道按 `Y'/Y` 等比缩放；`strength` 为均衡亮度与原亮度的混合比。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `blockSize` / 分块大小 | 32 | 8 ~ 128 | 均衡 tile 边长（像素）。调小：局部适应性更强、细节增强更激进，但 tile 内统计样本少、噪声更易被放大；调大：趋近全局直方图均衡，效果平和。边缘不足一块的 tile 按实际大小统计。 |
| `clipLimit` / 对比度限幅 | 2.0 | 1.0 ~ 10.0 | 直方图裁剪阈值（tile 平均计数的倍数）。调大：裁剪松、对比度增强更猛（噪声同步放大）；调小（→1）：增强受限、最接近"温和均衡"。 |
| `strength` / 强度 | 1.0 | 0 ~ 1 | 均衡结果与原图的混合比（亮度域混合）。0 = 原图直通（整帧跳过），1 = 全量均衡。 |

**注意事项**：

- 想进预览必须放在 **gamma 之前**（见 1.4：gamma 之后节点结果不进预览）；工具栏中它排在 gamma 之后是面向"gamma 出口后接输出/转换节点"的用法。
- 纯黑像素（Y = 0）无亮度比例可言，保持不动；均匀灰图经裁剪再分配后亮度基本不变（容差几个码值）。
- Mono 通路（`applyClaheMono`）处理 16 位 w*h 单通道帧，三个参数含义与 RGB 通路相同；典型用法是荧光 Mono 链上替代全局拉伸做局部对比度增强。
- 分块越多、clipLimit 越大，平坦区噪声越明显——低噪声素材可激进，高 ISO 素材建议 blockSize ≥ 32、clipLimit ≤ 2。

### 3.15 sat_bright_adjuster 色饱和度/亮度调节器

**功能**：RGB / YUV / HSL 三域通用的色饱和度与亮度调节（交互调参节点）。三个输入端口 `in`(RGB) / `in_yuv`(YUV) / `in_hsl`(HSL) 属视频输入互斥组，只能接入一路；三个输出端口 `out_rgb` / `out_yuv` / `out_hsl` **输出帧格式恒等于输入格式**（不做色彩空间转换，需要换格式请接 3.7–3.12 的 CSC 节点）。节点内嵌「调整前 | 调整后」双联预览与两个滑块（色饱和度、亮度），拖动滑块实时写参数、松手重跑流水线；带 Bypass 直通开关。

**算法原理**（`adjustSatBright`）：按输入帧所在色彩域处理，不跨域转换——

- **RGB 域**：先求 BT.601 全范围亮度 `Y = 0.299R + 0.587G + 0.114B`，逐通道做保亮度饱和度混合 `c' = Y + (c − Y) × satGain`，再整体乘 `brightGain`；
- **YUV 域**：`Y' = Y × brightGain`；`U/V` 围绕中点 `maxValue/2` 乘 `satGain`（色度增益不改变中性色点）；
- **HSL 域**：H 不变；`S' = S × satGain`，`L' = L × brightGain`。

结果均四舍五入后钳位到 `0..maxValue`；两个增益均为恒等 1 时直通不拷贝。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `sat_gain` / 色饱和度 | 1.0 | 0 ~ 8 | 色饱和度增益。0 = 去色（RGB 域变为 BT.601 灰度，YUV 域 U/V 回中性点，HSL 域 S 清零）；1 = 不变；>1 = 增艳，过大会钳位饱和。 |
| `bright_gain` / 亮度 | 1.0 | 0 ~ 32 | 亮度增益（乘性）。0 = 全黑；1 = 不变；>1 = 提亮，高光可能钳位。 |

**注意事项**：

- 输入端口接哪种格式，就在哪个域计算：同一组参数在三个域的视觉效果接近但不逐码值等价（RGB 域为保亮度混合，YUV/HSL 域为通道增益）。
- 预览对比图的「调整前」为输入链出图（到上游节点为止），「调整后」为本节点输出。
- GPU 快路径暂不支持本节点：含本节点的预览链自动回退 CPU isolate 执行，功能一致仅预览速度略慢。

### 3.16 bright_contrast_adjuster 亮度/对比度调节器

**功能**：RGB / YUV / HSL / Mono 四域通用的亮度/对比度调节（交互调参节点）。四个输入端口 `in`(RGB) / `in_yuv`(YUV) / `in_hsl`(HSL) / `in_mono`(Mono) 属视频输入互斥组，只能接入一路；输出主帧格式恒等于输入格式（不做色彩空间转换；Mono 域直接作用于单通道亮度）。输出端口 `out_rgb` / `out_yuv` / `out_hsl` 按输入格式取用主帧；`out_mono` 为**调整后亮度**的单通道图（w*h）：mono 输入即主帧本身，YUV 取 Y、HSL 取 L、RGB 按 BT.601 求亮度——可直接作混叠器蒙版等 mono 侧端口的输入。节点内嵌 **Y 通道波形示波器**（与 waveform 仪器同一口径：横轴图像列、纵轴 BT.601 亮度 0% 在底），黑色背景、左右双联——左半为**调整前**（输入链末端）波形，右半为**调整后**（本节点输出）波形；下排亮度/基线/增益三个滑块；带 Bypass 直通开关。

**算法原理**（`adjustBrightContrast`）：先算基线电平 `base = baseline/100 × maxValue`，再对亮度施加

```
Y' = ((Y × bright/100) − base) × gain/100 + base   （钳位 0..maxValue）
```

- **YUV 域**：直接作用于 Y 通道（U/V 不变）；
- **HSL 域**：作用于 L 通道（H/S 不变）；
- **RGB 域**：逐像素求 BT.601 亮度 `Y = 0.299R + 0.587G + 0.114B`，按 `Y'/Y` 等比缩放 R/G/B（保色调/饱和度；Y=0 纯黑像素保持 0）。

`bright=100 且 gain=100` 时为恒等（与基线无关），核内直通不拷贝。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `bright` / 亮度 | 100 | 0 ~ 1000 | 亮度百分比（乘性预缩放）。100 = 不变；<100 压暗、>100 提亮。 |
| `baseline` / 基线 | 50 | 0 ~ 100 | 对比度支点（满量程百分比）。调节围绕基线展开：低于基线的部分与高于基线的部分按增益反向拉开/收拢。示波器上以**绿色 1px 水平虚线**标出（仅画在左半「调整前」波形区），左缘有**三角形滑块**，可直接垂直拖动（等价于拖 Baseline 滑块）。 |
| `gain` / 增益 | 100 | 0 ~ 1000 | 对比度增益（相对基线的斜率百分比）。100 = 不变；>100 拉对比（离基线越远拉得越开，两端可能钳位）；<100 收对比（向基线压缩）；0 = 整帧压平到基线电平。 |

**注意事项**：

- 波形数据源为默认色调映射后的 8 位 RGBA（与 waveform 仪器一致），非 16 位原始域。
- 同一组参数在三个域的视觉效果接近但不逐码值等价（RGB 域为等比缩放，YUV/HSL 域为单通道调节）。
- GPU 快路径暂不支持本节点：含本节点的预览链自动回退 CPU isolate 执行，功能一致仅预览速度略慢。

### 3.17 levels_curves 曲线调节器

**功能**：RGB 域传递函数（色阶/曲线）调节（交互调参节点）。输入端口 `in`(RGB)，输出端口 `out`(RGB)，帧格式不变。节点内嵌**曲线编辑器**：黑色背景叠加**输入 Y 通道直方图**（对数刻度，半透明白）与**输出（调节后）Y 通道直方图**（对数刻度，`#605040`，叠在输入直方图之上），曲线为 `#FFD0B0`，X 轴为输入值、Y 轴为输出值，值域固定 0..4095；左缘竖条为输出灰阶（上白下黑）、底缘横条为输入灰阶（左黑右白）。带 Bypass 直通开关。

**算法原理**：端点 A1(0,0) 与 C1(4095,4095) 固定，用户在其间加入控制点 Bn；所有点按 `curveMode` 参数选择的**生成公式**连成传递函数曲线 y = f(x)：

- `spline`（默认）：**Fritsch–Carlson 单调三次 Hermite 插值**——单调的控制点序列产生单调曲线，段内无过冲；
- `bezier`：**贝塞尔曲线**——控制点整体作为贝塞尔控制多边形，De Casteljau 求值；控制点 x 单调递增保证 x(t) 单调不减，对给定 x 二分反解参数 t 后取 y(t)。曲线只保证过首尾端点，中间控制点牵引形状但不一定经过（贝塞尔控制多边形的固有特性）；
- `linear`：**线段法**——控制点间直线连接，不做平滑处理；
- `gamma`：**gamma 曲线**——y = max·(x/max)^(1/γ)（γ 取 `gamma` 参数：=1 恒等，>1 提亮中间调，<1 压暗）。该模式下编辑器**只允许一个控制点**（点按/拖动曲线区任意位置即移动它），控制点恒落在对应的 gamma 曲线上（拖动时由点位置反解 γ 并写回 `gamma` 参数），拖动中控制点旁显示 γ 值气泡。

曲线生成 4096 级 LUT，RGB 帧逐通道查表：帧值先按 `maxValue` 线性缩放到 0..4095 域，查表后再缩放回 0..maxValue（`maxValue == 4095` 时直通查表）。所有控制点都在对角线上（gamma 模式为 γ=1）时为恒等，核内直通不拷贝。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `curveMode` / 曲线公式 | `spline` | `spline` / `bezier` / `linear` / `gamma` | 曲线生成公式（见上）。切换后立即重跑预览；切到 `gamma` 时控制点收敛为唯一中间点。 |
| `gamma` / Gamma | `1.0` | 0.1 ~ 10 | 仅 `curveMode == gamma` 时生效：y = max·(x/max)^(1/γ)。在面板中直接设置后曲线与编辑器控制点同步（点 y 由 γ 推出）。 |
| `points`（隐式参数，不在属性面板出现） | `[[0,0],[4095,4095]]` | 各分量 0 ~ 4095 | 控制点列表 `[[x,y],…]`，随 `.ispflow` 一起保存。曲线区长宽比恒定 1:1（边长取可用空间短边，整体居中）。编辑器交互：单击空白**加点**、拖动**移点**（中间点 x 限制在相邻点之间，端点 x 固定；命中半径恒定 12 屏幕像素，随画布缩放自适应）、**拖住控制点移出曲线区（含 16px 容差，约等于移出节点附加区）即删除该点**（端点不可删）。拖动只写参数（曲线实时重绘），松手才重跑流水线。 |

**注意事项**：

- 直方图源为输入链/输出链末端默认色调映射后的 8 位 RGBA（2x2 降采样后统计，视觉等效）：半透明直方图反映**调整前**的亮度分布，`#605040` 直方图反映**调整后**的亮度分布。
- GPU 快路径暂不支持本节点：含本节点的预览链自动回退 CPU isolate 执行，功能一致仅预览速度略慢。

### 3.18 color_balance 色彩平衡

**功能**：RGB/YUV/HSL 三域中间调色彩偏移（交互调参节点）。互斥输入组 `in`(RGB) / `in_yuv`(YUV) / `in_hsl`(HSL)，同格式三路输出 `out_rgb` / `out_yuv` / `out_hsl`，帧格式不变。节点内嵌**调试块**：双联对比预览（左**调整前**（输入链出图）/右**调整后**（输出链出图），与 RGB 调节器同一布局）+ 青↔红 / 洋红↔绿 / 黄↔蓝 三行渐变滑杆（轨道按对应色相渐变，直观表达偏移方向）；数值输入走右侧属性面板。带 Bypass 直通开关。

**算法原理**：三个滑杆值 [-100, 100] 对应三个对立色轴的偏移：正值向红/绿/蓝偏移，负值向青/洋红/黄偏移。按 BT.601 亮度的**中间调权重** `w = 1 − |2Y − 1|` 加权——中间调偏移最强，纯黑/纯白像素不受影响。结果钳位到 0..maxValue。三值全 0 时核内直通不拷贝。各域实现：

- **RGB 域**：偏移量 = 值/100 × `maxValue`，直接加到 R/G/B 通道；
- **YUV 域**：青↔红即 V 轴（V ≈ R−Y）、黄↔蓝即 U 轴（U ≈ B−Y），洋红↔绿为 U/V 对角（绿 = −U−V，洋红 = +U+V）；色度偏移量 = 值/100 × `maxValue`/2，Y 通道不变；
- **HSL 域**：无直接的通道对应关系，经 hslToRgb/rgbToHsl 往返转换施加 RGB 域偏移（语义与 RGB 输入一致）。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `cyan_red` / 青色 ↔ 红色 | 0.0 | -100 ~ 100 | R 通道偏移。正值加红（暖调），负值减红偏青（冷调）。中间调最明显。 |
| `magenta_green` / 洋红 ↔ 绿色 | 0.0 | -100 ~ 100 | G 通道偏移。正值加绿，负值偏洋红。可用于校正品红/绿色偏色。 |
| `yellow_blue` / 黄色 ↔ 蓝色 | 0.0 | -100 ~ 100 | B 通道偏移。正值加蓝（冷调），负值减蓝偏黄（暖调）。 |

**注意事项**：

- 滑杆拖动只写参数（数值实时刷新），松手才重跑流水线；属性面板数值提交后立即重跑。
- GPU 快路径暂不支持本节点：含本节点的预览链自动回退 CPU isolate 执行，功能一致仅预览速度略慢。

### 3.19 color_temp_adjuster 色温调节器

**功能**：RGB 域色温调整（交互调参节点）。输入端口 `in`(RGB)，输出端口 `out_rgb`(RGB)，帧格式不变。节点内嵌**调试块**：双联对比预览（左调整前/右调整后）+ 实测/目标色温行（测量值为可点击按钮）+ **暖（橙）→冷（蓝）渐变色温滑杆**（1800~12000K）+ 底行（左下 **CCM 3x3 方框**——当前增益对角阵的 9 个矩阵值各用一个长方框显示，每行背景为对应通道的 RGB 颜色（R 行红底 / G 行绿底 / B 行蓝底，对角元略亮一档）；右下**调整后 RGB 通道直方图**，对数刻度三色叠加）。带 Bypass 直通开关。

**算法原理**：von Kries 对角增益模型。白点由 Tanner Helland 黑体辐射近似得到（归一化 G=1），通道增益：

```
gain[c] = white(temperature)[c] / white(measured_cct)[c]   c ∈ R/G/B
```

逐像素 R/G/B 乘增益（复用白平衡增益核 adjustRgb），结果钳位到 0..maxValue。目标 == 参考时三通道增益恰为 1，核内直通不拷贝。节点显示的 CCM 即 `diag(gR, gG, gB)`。

**色温测量**：运行预览时由输入链末端 RGBA 估计相关色温——步长抽样取平均 RGB，经 sRGB→XYZ 矩阵求色度 (x, y)，代入 McCamy 公式 `CCT = 449n³ + 3525n² + 6823.3n + 5520.33`（`n = (x−0.3320)/(0.1858−y)`），钳位到 1800~12000K。测量值在节点上显示为**可点击按钮**：点击后滑块（目标色温）设为该测量值，同时参考色温隐式参数 `measured_cct` 一并设为该值——目标==参考，增益恒等，即以当前实测色温为基准，随后拖动滑块相对该基准调节。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `temperature` / 色温 (K) | 6500.0 | 1800 ~ 12000 | 目标色温。高于实测值画面偏冷（加蓝减红），低于实测值偏暖。未测量时相对 D65 6500K 调节。 |
| `measured_cct`（隐式参数，不在属性面板出现） | 无 | 1800 ~ 12000 | 参考（基准）色温：点击节点的测量值按钮时与目标色温一并写入（缺省按 6500K），随 `.ispflow` 保存。 |

**注意事项**：

- 滑块拖动只写参数（数值与 CCM 实时刷新），松手才重跑流水线；属性面板数值提交后立即重跑。
- 测量只更新显示，不改参数：运行后「测量」按钮显示实测色温，点击它才把滑块设为测量值（同时把参考基准设为同一值，画面不变）。
- GPU 快路径支持本节点（复用白平衡/RGB 调节器的通道增益 shader）；链被 GPU 覆盖时色温测量由 GPU 回读上游端口 RGBA 补齐，与 CPU 闭包同一口径。

### 3.20 morphology 腐蚀/膨胀

**功能**：形态学方形结构元滤波——腐蚀（erode，邻域极小值）收缩亮区域、去除小亮点；膨胀（dilate，邻域极大值）扩张亮区域、填补小暗洞。RGB 三通道独立处理（`in`/`out` 端口）与 Mono 单通道灰度形态学（`in_mono`/`out_mono` 端口，互斥只接一路），帧格式不变。

**算法原理**（`applyMorphology`）：`(2×radius+1)²` 方形窗口逐通道取极小/极大值；可分离两趟实现（水平一趟 + 垂直一趟），结果与直接二维窗口完全一致，复杂度从 O(r²) 降为 O(r)。边界按可用邻域取极值（窗口裁剪到图内）；极值取自原数据本身，无需钳位。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `mode` / 模式 | erode | erode / dilate | 腐蚀（极小）/ 膨胀（极大），下拉双语显示。 |
| `radius` / 半径 | 1 | 1 ~ 8 | 结构元半径，窗口边长 2r+1。调大作用范围更粗，细节丢失更多。 |

**注意事项**：

- 放在 gamma 之前（线性域操作）。
- 黑底白线图（如 edge_extract 的 out_mono）上做**腐蚀**会把细线整体抹黑（半径 1 即抹掉大部分），观察效果请用膨胀；腐蚀适合亮区域/灰度图上去除孤立亮点。
- GPU 快路径已支持本节点（`shaders/isp/isp_morphology.frag`，同一 shader 跑水平/垂直两趟，常量循环界 r≤8，与 CPU 逐值一致）。

## 4. Process → Fluorescence 子分组（荧光 mono 域）

荧光支链以 `cis_mono` 源（或 RAW 域节点的 mono 端口）为起点，帧格式为 `mono`（`w*h` Uint16List）。本节节点除 pseudo_color / fluoro_fusion 外输入输出均为 mono。

### 4.1 fluoro_leak 激发泄漏扣除

**功能**：扣除激发光（近红外激发源）泄漏进荧光通道的固定电平（方案 N17/N18）。

**算法原理**（`applyFluoroLeak`）：

```
sub = min(level, maxSub)
v' = max(0, v − sub)      （sub ≤ 0 时整帧跳过）
```

全帧统一常量扣除，`maxSub` 是保险限幅。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `level` / 扣除电平 | 64.0 | 0 ~ 65535 | 要扣掉的泄漏电平估计值（码值）。应由"激发开、无荧光团"的参考帧统计得到。调大：扣除更狠，弱荧光信号可能连同被截零；调小：泄漏残留、背景发绿。 |
| `maxSub` / 最大扣除限幅 | 128.0 | 0 ~ 65535 | 实际扣除量的上限：`level` 超过它时按它扣。防止参数误填（如把 level 填成满量程）导致整帧归零。调试期建议保持较小的保守值。 |

**注意事项**：它只能扣"空间均匀"的泄漏；泄漏随视野不均匀时应改用 fluoro_background 兜底或改善光机滤光片。

### 4.2 fluoro_background 背景扣除

**功能**：扣除自发荧光等低频背景（组织自体在激发下的宽谱发光，方案 N19/N20）。

**算法原理**（`applyFluoroBackground`）：

1. 把全图切成 `blockSize × blockSize` 的块（最小 2，边缘块截断），逐块求均值作为局部背景估计 `bg`；
2. `v' = v − strength × bg`，截零；`strength ≤ 0` 时整帧跳过。

是空间分块的低频扣除，非逐像素滤波。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `blockSize` / 块大小 | 16 | 2 ~ 256 | 背景估计块边长（像素）。调大：背景曲面更平滑，但会吃掉与块同尺度的真实荧光团（大光斑被当背景扣掉）；调小：跟随局部起伏，残留背景多、且块边界可能产生棋盘格。应明显大于目标荧光团的典型尺寸。 |
| `strength` / 强度 | 1.0 | 0 ~ 1 | 背景扣除比例。1.0 = 全额扣除（背景区域归零）；<1 保留部分背景作解剖学参照。0 = 关闭。 |

**注意事项**：块均值无重叠平滑，强背景梯度下块间有台阶感；必要时块大小取大一点、强度略小于 1。

### 4.3 fluoro_normalize 激发归一化

**功能**：补偿激发光强波动——把全帧均值增益拉到参考电平（方案 N21–N23）。

**算法原理**（`applyFluoroNormalize`）：

```
mean = 全帧均值
若 mean < epsilon：整帧跳过（视为无有效信号，不放大噪声）
gain = reference / mean
v' = clamp(v × gain, 0, maxValue)
```

`reference ≤ 0` 时整帧跳过；`gain == 1.0` 时跳过。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `reference` / 参考电平 | 1000.0 | 0 ~ 65535 | 目标平均电平（码值）。当前帧均值偏离它时按比值整体放大/缩小。应按标定工况下的典型荧光均值设置；设得过高会把弱信号帧连同噪声一起放大。0 = 关闭。 |
| `epsilon` / 除法下限 | 1.0 | 0 ~ 1024 | 均值有效性门限：均值低于它时**整帧不处理**（实现是直接 return，而不是把分母钳位到 epsilon——与核注释 `max(mean, epsilon)` 的表述略有出入，以代码行为为准）。防止暗场帧被天文数字增益放大成全噪声图。 |

**注意事项**：以"全帧均值"代理激发强度是简化实现——画面内容变化（荧光团进入/离开视野）也会被当成激发强度变化而补偿，严格做法应外接激发参考光电二极管信号。

### 4.4 fluoro_temporal 时域 IIR 降噪

**功能**：跨帧一阶 IIR 递归滤波，压低随机噪声（方案 N26–N28）。

**算法原理**（`applyTemporalIir` + runner 的历史缓存）：

```
Y[n] = α × F[n] + (1 − α) × Y[n−1]
```

- 运动自适应开启时：`|F − Y[n−1]| > maxValue/16` 的像素判为运动，强制 `α = 1`（直接用当前帧，避免拖影）；
- 历史帧按节点 id 缓存在常驻 worker 内；帧号不连续、分辨率或参数变化时历史重置，该帧直通并把自身作为新历史；
- 单帧 compute()（一次性 isolate）无历史，行为为直通。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围 | 说明与调整效果 |
| --- | --- | --- | --- |
| `alpha` / α（当前帧权重） | 0.5 | 0 ~ 1 | 当前帧权重。调小：历史权重加大，降噪更强、静态画面更干净，但运动拖影加重（时间常数 ≈ 1/α 帧）；调大到 1 = 无滤波直通。静止/缓变场景 0.2~0.4， handheld 抖动大时 ≥0.6。 |
| `motionAdapt` / 运动自适应 | true | 布尔 | 开：帧差超过 `maxValue/16` 的像素退出滤波（运动区不拖影，代价是运动区噪声不滤）；关：全图统一递归，静态最好、运动拉丝明显。一般保持开启。 |

**注意事项**：只在连续播放（常驻 worker、帧号连续）时有实际效果；单帧调试/图片输出路径等价于直通，不要用它评估单帧画质。

### 4.5 pseudo_color 伪彩映射

**功能**：把荧光 mono 灰度映射为伪彩 RGB，供单独预览荧光通道（方案 N33/N40）。

**算法原理**（`monoPseudoColor`）：

```
t = clamp(mono × gain / maxValue, 0, 1)
green:   (0, t, 0)                （ICG 荧光惯例纯绿）
magenta: (t, 0, t)
hot:     r = min(3t, 1)，g = clamp(3t − 1)，b = clamp(3t − 2)   （黑→红→黄→白）
```

输出 16 位量级交织 RGB（帧格式变为 `rgb`）。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围/选项 | 说明与调整效果 |
| --- | --- | --- | --- |
| `colormap` / 色表 | green | green / magenta / hot | green 是 ICG 影像的行业惯例；magenta 用于与白光绿色组织形成更高区分度；hot 保留强度层次信息最多（三段式）。 |
| `gain` / 增益 | 1.0 | 0 ~ 8 | 映射前的线性增益。弱信号调大（>1）让低码值也进入可见色段，代价是高信号提前饱和到色表顶端；信号强时调小扩大动态范围。 |

**注意事项**：本节点是 mono 域的出口之一；若荧光要叠加到白光画面上，不要用它，直接用 fluoro_fusion（融合内部自带同一套色表）。

### 4.6 fluoro_fusion 荧光融合

**功能**：白光 RGB 与荧光 mono 双源融合出图（方案 R09–R11、N38/N39；几何配准 R01–R07 与 SBR/置信度 N29/N30/N38 的简化折叠）。

**算法原理**（`fuseFluorescence`）：

1. **配准**：荧光图按 `(offsetX, offsetY)` 手动偏移做双线性重采样（边界钳位），采样坐标 `(x+offsetX, y+offsetY)`；
2. **α 映射**（mode = alpha，默认）：荧光强度经门限映射到融合系数

```
fl > threshold 时：a = alphaMax × (fl − threshold) / (maxValue − threshold)，封顶 alphaMax
否则 a = 0
RGB' = WL×(1 − a) + pseudo(fl)×a        （伪彩增益恒为 1）
```

3. **轮廓模式**（mode = contour）：`fl ≥ threshold` 构成 mask，mask 内像素的 3x3 邻域（同样带偏移采样）存在 mask 外点即为边缘；边缘像素以伪彩**全强度**叠加，其余像素保持白光原样；
4. `in_fluoro` 未连接或荧光帧尺寸与白光不一致时：**白光直通**（不报错）。

**参数说明**：

| 参数 (key / 标签) | 默认值 | 范围/选项 | 说明与调整效果 |
| --- | --- | --- | --- |
| `mode` / 模式 | alpha | alpha / contour | alpha：荧光按强度半透明叠加，适合观察荧光强度分布；contour：只勾勒荧光区轮廓、不遮盖组织细节，适合术中导航。 |
| `threshold` / 荧光门限 | 128.0 | 0 ~ 65535 | 参与融合的最低荧光码值。调大：只保留强荧光区，假阳性（噪声/泄漏残留）被抑制；调小：弱信号可见，但噪声底色也浮现。应设在背景噪声之上。threshold ≥ maxValue 时 alpha 模式恒为白光直通。 |
| `alphaMax` / 最大 α | 0.8 | 0 ~ 1 | 融合系数上限。1.0 = 最强荧光处完全遮盖白光；0.8 保留 20% 组织纹理作参照。contour 模式下该参数无作用（轮廓恒为全强度）。 |
| `colormap` / 色表 | green | green / magenta / hot | 与 pseudo_color 同一套色表。 |
| `offsetX` / 配准偏移 X | 0.0 | −64 ~ 64 | 荧光图相对白光图的水平偏移（像素，支持小数，双线性插值）。双传感器物理装配有固有视差，用标定靶（点光源）对齐后填入。 |
| `offsetY` / 配准偏移 Y | 0.0 | −64 ~ 64 | 同上，垂直方向。 |

**注意事项**：

- 该节点是双源链的汇合点：`in` 接白光 RGB 链（通常在 gamma **之前**的线性 RGB），`in_fluoro` 接荧光 mono 链末端；含它的链允许 2 个源节点，第二个源必须是 RAW 源。
- 两路分辨率必须一致，否则荧光支路被静默忽略（白光直通）——排查"荧光没出来"时先查这一点，再查 threshold 是否过高。
- 融合输出是 RGB 线性域，其后还应接 gamma 再预览。

## 5. 附：核对实现时发现文档性表述与代码行为的差异

以下差异不影响正常使用，记录备查（以代码行为为准）：

1. `applyFluoroNormalize` 的核注释写 `v' = v × reference / max(mean, epsilon)`，实现实际是 `mean < epsilon` 时整帧直通（不放大），二者仅在 `0 < mean < epsilon` 时有区别。
2. `applyFpn` 的 `radius`（低通窗/掩膜膨胀半径，默认 8）未在节点参数中暴露，界面不可调。
3. `applyGrGbBalance` 的结果截位常量硬编码为 65535，未像其他核一样使用 `maxValue`；对低位深源等价于不截位。
4. `csc_rgb2yuv` 选择 bt709 或 limited 后，链末端预览固定以 BT.601 全范围逆变换回 RGB，预览存在轻微色差（数据本身正确）。
5. black_level 节点的 `gr/gb/b` 三个参数在 mono 输入路径下不生效（mono 只读 `r`），非 Bayer CFA 输入按 RGGB 相位近似。
