:MASK:Y

　

　

命令格式

　

:MASK:Y <y>
:MASK:Y?


　

功能描述

　

设置通过/失败测试的规则中的垂直调整参数。

　

　

参数

　

名称

 类型 范围

默认值

<y>

 实型

0.03至4

0.375

注：在取值范围内步进为0.03125，示波器显示小数点后两位。

　

 

返回格式

　

查询以科学计数形式返回当前的垂直调整参数。

　

　

举例

　

下面的命令设置垂直调整为0.38。


 :MASK:Y 0.38

下面的查询返回3.750000e-01（与0.03125步进有关）。


:MASK:Y?
