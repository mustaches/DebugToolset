:SYSTem:UDEVice

　

　

命令格式

　

:SYSTem:UDEVice <udv>
:SYSTem:UDEVice?


　

功能描述

　

设置示波器使其与不同设备类型相匹配。示波器可通过后面板的USB Device接口与PC或打印机进行通信。

　

　

参数

　

名称

 类型 范围

默认值

<udv>

 离散型

{COMPuter|PICTbridge}

COMPuter

　

 

返回格式

　

查询返回COMP或PICT。

　

　

举例

　

下面的命令设置示波器与PICTbridge匹配。


 :SYSTem:UDEVice PICTbridge

下面的查询返回PICT。


:SYSTem:UDEVice?
