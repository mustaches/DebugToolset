:SYSTem:ETIMpedence

　

　

命令格式

　

:SYSTem:ETIMpedence <impedance>
:SYSTem:ETIMpedence?


　

功能描述

　

设置外触发输入阻抗为OMEG（1 MΩ）或FIFT（50 Ω）。

　

　

参数

　

名称

 类型 范围

默认值

<impedance>

离散型

{OMEG|FIFT}

OMEG

　

 

返回格式

　

查询返回OMEG或FIFT。

　

　

举例

　

下面的命令设置外触发输入阻抗为50 Ω。

 :SYSTem:ETIMpedence FIFT

下面的查询返回FIFT。

 :SYSTem:ETIMpedence?
