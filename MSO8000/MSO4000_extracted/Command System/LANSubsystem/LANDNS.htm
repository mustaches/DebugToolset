:LAN:DNS 

　

　

命令格式

　

:LAN:DNS <string>
:LAN:DNS?


　

功能描述

　

设置域名服务器的地址。

　

　

参数

　

名称

 类型 范围

默认值

<string>

 ASCII字符串

nnn,nnn,nnn,nnn

0,0,0,0

　

 

说明

　

设置<string>时，第一个nnn的范围为0至223（127除外），其他三个nnn的范围为0至255。

使用该命令时，IP配置模式应为手动（参考:LAN:MANual命令）或自动（参考:LAN:AUToip命令）模式。

　

　

返回格式

　

查询以字符串形式返回当前的域名服务器地址。

　

　

举例

　

下面的命令设置域名服务器地址为172.16.2.2。

 :LAN:DNS 172,16,2,2

下面的查询返回172.16.2.2。

 :LAN:DNS?
