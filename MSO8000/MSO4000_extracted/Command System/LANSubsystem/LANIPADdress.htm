:LAN:IPADdress 

　

　

命令格式

　

:LAN:IPADdress <string>
:LAN:IPADdress?


　

功能描述

　

设置仪器的IP地址。

　

　

参数

　

名称

 类型 范围

默认值

<string>

 ASCII字符串

nnn,nnn,nnn,nnn

0,0,0,0

　

 

说明

　

设置<string>时，第一个nnn的范围为0至223（127除外），其他三个nnn的范围为0至255。

使用该命令时，IP配置模式应为手动模式（参考:LAN:MANual命令）。

　

　

返回格式

　

查询以字符串形式返回当前的IP地址。

　

　

举例

　

下面的命令设置IP地址为172.16.3.118。

 :LAN:IPADdress 172,16,3,118

下面的查询返回172.16.3.118。

 :LAN:IPADdress?
