:FUNCtion:WANalyze:MODE

　

　

命令格式

　

:FUNCtion:WANalyze:MODE <mode>
:FUNCtion:WANalyze:MODE?


　

功能描述

　

设置波形分析模式。

　

　

参数

　

名称

 类型 范围

默认值

<mode>

 离散型

{TRACe|MASK}

TRACe

　

 

返回格式

　

查询返回TRAC或MASK。

　

　

举例

　

下面的命令选择轨迹模式。


 :FUNCtion:WANalyze:MODE TRACe

下面的查询返回TRAC。


 :FUNCtion:WANalyze:MODE?
