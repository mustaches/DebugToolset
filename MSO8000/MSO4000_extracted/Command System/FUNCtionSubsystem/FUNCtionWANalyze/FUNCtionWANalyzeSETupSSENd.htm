:FUNCtion:WANalyze:SETup:SSENd

　

　

命令格式

　

:FUNCtion:WANalyze:SETup:SSENd <NR1>
:FUNCtion:WANalyze:SETup:SSENd?


　

功能描述

　

设置波形分析的屏幕终点。

　

参数

　

名称

 类型 范围

默认值

<NR1>

 整型

15至695

695

　

　

返回格式

　

查询返回一个整数。

　

　

举例

　

下面的命令设置波形分析的屏幕终点是20。


 :FUNCtion:WANalyze:SETup:SSENd 20

下面的查询返回20。


 :FUNCtion:WANalyze:SETup:SSENd?
