:FUNCtion:WANalyze:SOURce

　

　

命令格式

　

:FUNCtion:WANalyze:SOURce <sour>
:FUNCtion:WANalyze:SOURce?


　

功能描述

　

选择需要分析的通道源。

　

　

参数

　

名称

 类型 范围

默认值

<sour>

 离散型

{CHANnel1|CHANnel2|CHANnel3|CHANnel4}

CHANnel1

注：通道源只能选择当前打开的通道。

 
　

返回格式

　

查询返回CHAN1、CHAN2、CHAN3或CHAN4。

　

　

举例

　

下面的命令设置通道2作为通道源。


 :FUNCtion:WANalyze:SOURce CHAN2

下面的查询返回CHAN2。


 :FUNCtion:WANalyze:SOURce?
