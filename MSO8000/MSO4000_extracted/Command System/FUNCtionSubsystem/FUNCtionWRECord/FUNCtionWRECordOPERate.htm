:FUNCtion:WRECord:OPERate

　

　

命令格式

　

:FUNCtion:WRECord:OPERate <oper>
:FUNCtion:WRECord:OPERate?


　

功能描述

　

启动或停止波形录制。

　

　

参数

　

名称

 类型 范围

默认值

<oper>

 离散型

{RECord|STOP}

STOP

　

 

返回格式

　

查询返回REC或STOP。

　

　

举例

　

下面的命令启动波形录制。


 :FUNCtion:WRECord:OPERate RECord


下面的查询返回REC。


 :FUNCtion:WRECord:OPERate?
