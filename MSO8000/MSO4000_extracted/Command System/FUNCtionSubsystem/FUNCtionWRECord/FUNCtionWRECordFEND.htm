:FUNCtion:WRECord:FEND

　

　

命令格式

　

:FUNCtion:WRECord:FEND <frame>
:FUNCtion:WRECord:FEND?


　

功能描述

　

设置波形录制的终止帧数。

当前可设置的最大终止帧数可通过:FUNCtion:WRECord:FMAX?命令查询。

　

　

参数

　

名称

 类型 范围

默认值

<frame>

 整型

1至当前可录制的最大帧数

----

　

　

说明

　

由于波形存储器大小是固定的，每帧波形的点数越多，能录制的波形帧数越少。

因此，波形录制的最大终止帧数取决于当前选择的存储深度。

 

　

返回格式

　

查询返回一个整数。

　

　

举例

　

下面的命令设置终止帧数为999。


 :FUNCtion:WRECord:FEND 999

下面的查询返回999。


:FUNCtion:WRECord:FEND?
