:MEASure:CLEar

　

　

命令格式

　

:MEASure:CLEar <item>


　

功能描述

　

清除最先打开的5个测量项中的任一项或所有项。

　

　

参数

　

名称

 类型 范围

默认值

<item>

 离散型

{ITEM1|ITEM2|ITEM3|ITEM4|ITEM5|ALL}

----

　

　

说明

　

前5项参数是根据您打开测量项的顺序决定的，不会因为您删除了一个或多个测量项而改变。

清除某项或所有测量项后，您还可以用:MEASure:RECover命令恢复。

　

　

举例

　

下面的命令清除第二个测量项。


 :MEASure:CLEar ITEM2
