:TRIGger:IIC:WHEN

　

　

命令格式

　

:TRIGger:IIC:WHEN <trig_type>
:TRIGger:IIC:WHEN?


　

功能描述

　

选择IIC触发的触发条件为：启动，重启，停止，丢失确认，地址，数据，地址数据。

　

　

参数

　

名称

 类型 范围

默认值

<trig_type>

 离散型

{STARt|STOP|NACKnowledge|RESTart|ADDRess|DATA|ADATa}

STARt

　

 

返回格式

　

查询返回STAR、STOP、NACK、REST、ADDR、DATA或ADAT。

　

　

举例

　

下面的命令设置触发条件为重启。


 :TRIGger:IIC:WHEN RESTart

下面的查询返回REST。


:TRIGger:IIC:WHEN?
