:TRIGger:IIC:DIRection

　

　

命令格式

　

:TRIGger:IIC:DIRection <dir>
:TRIGger:IIC:DIRection?


　

功能描述

　

设置IIC触发下，触发条件为地址 或地址数据时的数据方向 。

欲设置IIC触发条件，请参考:TRIGger:IIC:WHEN命令。

　

　

参数

　

名称

 类型 范围

默认值

<dir>

 离散型

{READ|WRITe|RWRite}

READ

　

 

返回格式

　

查询返回READ、WRIT或RWR。

　

　

举例

　

下面的命令设置数据方向为读/写。


 :TRIGger:IIC:DIRection RWRite

下面的查询返回RWR。


:TRIGger:IIC:DIRection?
