:TRIGger:FLEXray:BAUD

　

　

命令格式

　

:TRIGger:FLEXray:BAUD <baud>
:TRIGger:FLEXray:BAUD?


　

功能描述

　

选择FlexRay触发的信号速率。单位为b/s。

　

　

参数

　

名称

 类型 范围

默认值

<baud>

 离散型

{2500000|5000000|10000000}

2500000

　

 

返回格式

　

查询返回当前设置的信号速率。

　

　

举例

　

下面的命令设置信号速率为5 Mb/s。


 :TRIGger:FLEXray:BAUD 5000000

下面的查询返回5000000。


:TRIGger:FLEXray:BAUD?
