:TRIGger:CAN:STYPe

　

　

命令格式

　

:TRIGger:CAN:STYPe <signal_type>
:TRIGger:CAN:STYPe?


　

功能描述

　

选择CAN触发的信号类型。

　

　

参数

　

名称

 类型 范围

默认值

<signal_type>

 离散型

{H|L|RX|TX|DIFFerential}

RX

　

 

返回格式

　

查询返回H、L、RX、TX或DIFF。

　

　

举例

　

下面的命令设置信号类型为差分信号。


 :TRIGger:CAN:STYPe DIFFerential

下面的查询返回DIFF。


:TRIGger:CAN:STYPe?
