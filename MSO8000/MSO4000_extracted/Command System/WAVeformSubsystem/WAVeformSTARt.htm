:WAVeform:STARt

　

　

命令格式

　

:WAVeform:STARt <sta>
:WAVeform:STARt?


　

功能描述

　

设置内存中波形被读取的起始位置。受当前波形读取模式的限制（参考:WAVeform:MODE命令）。

　

　

参数

　

名称

 类型 范围

默认值

<sta>

 整型

NORMal：1至 1400

MAX：1至当前屏幕的有效点数

RAW：1至当前最大的存储深度

----

　

 

说明

　

有关存储深度，请参考:ACQuire:MDEPth命令。

　

　

返回格式

　

查询返回一个整数。

　

　

举例

　

下面的命令设置起始位置为100。


 :WAVeform:STARt 100

下面的查询返回100。


:WAVeform:STARt?
