*TST?

　

　

命令格式

　

*TST?

　

　

功能描述

　

执行一次自检并返回自检结果。

　

　

说明

　

返回值是一个十进制整数，范围为0至2147483647（231-1），对应32bit的二进制数，每bit代表的自检项目如下：

BIT0: SYSTEM VOLTAGE 3.3
BIT1: ANA VOL
BIT2: STORAGE VOL
BIT3: DIG CORE VOL
BIT4: DIG PER VOL

BIT8: BATT
BIT9: FAN1
BIT10:FAN2

BIT12: TEMPE1
BIT13: TEMPE2

BIT16: TMO

注：BIT5~BIT7， BIT11，BIT14~BIT15，BIT17~BIT31为预留位。

　


返回格式

　

查询返回一个十进制整数，对应二进制位上为0表示自检通过，为1表示自检失败。
