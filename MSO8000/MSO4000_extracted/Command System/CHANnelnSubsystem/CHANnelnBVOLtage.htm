:CHANnel<n>:BVOLtage

　

　

命令格式

　

:CHANnel<n>:BVOLtage <val>
:CHANnel<n>:BVOLtage?


　

功能描述

　

设置差分探头的偏置电压。示波器可为差分探头提供偏移电压，此偏移电压用于将超出探头放大

器输入动态范围的被测信号调整至适当的范围，以保证被测信号的完整性。

　

　

参数

　

名称

 类型 范围

默认值

<n>

离散型

{1|2|3|4}

1

<val>

实型

-12至+12

 0

　

　

说明

该命令仅在接入差分探头时有效。
　

 

返回格式

　

查询值以科学计数的形式返回。

　

　

举例

　

下面的命令设置偏置电压 为1.24 V。

 :CHANnel1: BVOLtage 1.24

下面的查询返回1.240000e+00。

 :CHANnel1:BVOLtage?
