:CHANnel<n>:TCALibrate

　

　

命令格式

　

:CHANnel<n>:TCALibrate <val>
:CHANnel<n>:TCALibrate?


　

功能描述

　

设置一个延迟时间以校正对应通道的零点偏移。

　

　

参数

　

名称

 类型 范围

默认值

<n>

离散型

{1|2|3|4}

 1

<val>

实型

-100ns至+100ns

 0

　

　

说明

 该参数的设置与当前设置的水平时基的大小有关，例如：水平时基为5us时，可设置延迟时间的步进为100ns，当水平时基为1us 时，可设置延迟时间的步进为20ns，当水平时基为500ns时，可设置延迟时间步进为10ns。
　

 

返回格式

　

查询值以科学计数的形式返回。

　

　

举例

　

下面的命令设置延迟时间为50ns。

 :CHANnel1:TCALibrate 0.00000005

下面的查询返回5.000000e-08。

 :CHANnel1:TCALibrate?
