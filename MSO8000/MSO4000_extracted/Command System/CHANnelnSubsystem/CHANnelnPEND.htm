:CHANnel<n>:PEND

　

　

命令格式

　

:CHANnel<n>:PEND <type>
:CHANnel<n>:PEND?


　

功能描述

　

设置差分探头前端类型。

　

　

参数

　

名称

 类型 范围

默认值

<n>

离散型

{1|2|3|4}

1

<type>

离散型

{SEND|DIFFerential}

 SEND

　

　

说明

该命令仅在接入差分探头时有效。

SEND：单端探头前端；

DIFFerential：差分探头前端。

　

 

返回格式

　

查询返回SEND或DIFF。

　

　

举例

　

下面的命令设置差分探头前端类型为SEND。

 :CHANnel1:PEND SEND

下面的查询返回SEND。

 :CHANnel1:PEND?
