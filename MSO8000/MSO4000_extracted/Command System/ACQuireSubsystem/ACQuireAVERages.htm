:ACQuire:AVERages

　

　

命令格式

　

:ACQuire:AVERages <count>
:ACQuire:AVERages?


　

功能描述

　

设置平均采样次数。所设置的值为2的幂函数。

　

　

参数

　

名称

 类型 范围

默认值
<count> 整型 2至8192 2

　

 

说明

　

使用:ACQuire:TYPE命令可以选择平均获取方式。该方式下，示波器对多次采样的波形进行平均，

以减少输入信号上的随机噪声并提高垂直分辨率。平均次数越高，噪声越小并且垂直分辨率越高，

但显示的波形对波形变化的响应也越慢。

　

　

返回格式

　

查询返回一个整数。

　

　

举例

　

下面的命令将平均采样次数设为128。


 :ACQuire:AVERages 128

下面的查询返回128。


 :ACQuire:AVERages?
