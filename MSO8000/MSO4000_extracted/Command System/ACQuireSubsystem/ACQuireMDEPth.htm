:ACQuire:MDEPth

　

　

命令格式

　

:ACQuire:MDEPth <mdep>
:ACQuire:MDEPth?


　

功能描述

　

设置示波器在一次触发采集中所能存储的波形点数。

　

　

参数

　

名称

 类型 范围

默认值
<mdep> 离散型 参考说明 56000（单通道开启）
28000（双通道开启）

　

 

说明

　

单通道开启时：
 <mdep>可设置为AUTO|14000|140000|1400000|14000000|140000000。


双通道（CH1和CH2，CH3和CH4或更多）开启时：
 <mdep>可设置为AUTO|7000|70000|700000|7000000|70000000。

 

　

返回格式

　

查询返回实际点数（整数）。

　

　

举例

　

下面的命令将存储深度设置为1.4 Mpts。

 :ACQuire:MDEPth 1400000

下面的查询返回实际点数，如1400000。

:ACQuire:MDEPth?
