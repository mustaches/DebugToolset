:TIMebase:DELay:SCALe

　

　

命令格式

　

:TIMebase:DELay:SCALe <scale_value>
:TIMebase:DELay:SCALe?


　

功能描述

　

设置延迟时基档位。单位为s/div。

　

　

参数

　

名称

 类型 范围

默认值

<scale_value>

 实型 参考说明 0.5*主时基档位

　

　

说明

　

参数<scale_value>的最大值为当前的主时基档位值，最小值与当前的采样率有关（满足关系式：当前采样率 * 延迟时基档位 * 7 ≥ 14）且不小于1ns。

延迟时基档位仅能取最大值以及由最大值以1-2-5为步进递减所得的值。若按上述关系式计算所得的最小值不是可设置值，则向上取可设置值。若发送的数值介于两个可设置值之间，仪器则自动将延迟时基档位设置为较小的值。

 

例如：当前的主时基档位为10.00us，采样率为500MSa/s，则<scale_value>的最大值为10.00us，最小值按照上文的关系式计算：≥ 14 / (500MSa/s * 7) = 40ns。向上取可设置值，即50ns。此时，若发送参数值为0.000009（即9us），仪器接收命令后将延迟时基档位设置为5us。

　

　

返回格式

　

查询以科学计数形式返回水平档位值。

　

　

举例

　

下面的命令设置 延迟时基为50 ns/div。

 :TIMebase:DELay:SCALe 0.00000005

下面的查询返回5.000000e-08。

 :TIMebase:DELay:SCALe?
