:TIMebase:DELay:OFFSet

　

　

命令格式

　

:TIMebase:DELay:OFFSet <offset>
:TIMebase:DELay:OFFSet?


　

功能描述

　

设置延迟时基偏移。单位为s。

　

　

参数

　

名称

 类型 范围

默认值

<offset>

 实型 -(LeftTime - DelayRange/2)至(RightTime - DelayRange/2) 0

注：

LeftTime = 7×MainScale - MainOffset。对于MainScale，参考:TIMebase[:MAIN]:SCALe命令。

RightTime = 7×MainScale + MainOffset。对于MainOffset，参考:TIMebase[:MAIN]:OFFSet命令。

DelayRange = 14×DelayScale。对于DelayScale，参考:TIMebase:DELay:SCALe命令。

　

 

返回格式　

　

查询以科学计数形式返回偏移值。　

　

　

举例　

下面的命令设置延迟时基偏移为2 us。

 :TIMebase:DELay:OFFSet 0.000002

下面的查询返回2.000000e-06。

 :TIMebase:DELay:OFFSet?
