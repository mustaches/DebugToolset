:EXT:PEND

　

　

命令格式

　

:EXT:PEND <type>
:EXT:PEND?


　

功能描述

　

设置外部触发通道的差分探头前端类型。

　

　

参数

　

名称

 类型 范围

默认值

<type>

离散型

{SEND|DIFFerential}

 SEND

　

　

说明

该命令仅在接入差分探头时有效。

SEND：单端探头前端；

DIFFerential：差分探头前端。

 
　

返回格式

　

查询返回SEND或DIFF。

　

　

举例

　

下面的命令设置差分探头前端类型为SEND。

 :EXT:PEND SEND

下面的查询返回SEND。

 :EXT:PEND?
