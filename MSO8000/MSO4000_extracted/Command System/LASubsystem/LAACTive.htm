:LA:ACTive

　

　

命令格式

　

:LA:ACTive <digital>|<group>|none
 :LA:ACTive?


　

功能描述

　

设置当前活动通道为16个数字通道中的任一个或4组通道中的任一组，选择none则不设置活动通道。

　

　

参数

　

名称

 类型 范围

默认值

<digital>

离散型 D0 至 D15

D0

<group>

离散型

GROup1 至 GROup4

----



说明

　

只有包含数字通道的组才可以选择。

您可以使用:LA:GROup<n>:APPend命令为4个自定义组Group1至Group4添加数字通道。

同一数字通道只能属于一个组，不可以重复分组。
每组最多包含16个数字通道。

　

　

返回格式

　

查询返回D1至D15、GRO1至GRO4或NONE。

　

　

举例

　

下面的命令设置当前的活动通道为D5。

 :LA:ACTive D5 

下面的查询返回D5。

 :LA:ACTive?
