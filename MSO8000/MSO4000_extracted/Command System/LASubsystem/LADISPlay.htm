:LA:DISPlay

　

　

命令格式

　

:LA:DISPlay <digital>|<group>|<pod>,<state>
 :LA:DISPlay? <digital>|<group>|<pod>


　

功能描述

　

打开或关闭16个数字通道中的任一个或4组通道中的任一组，或两个默认的通道组D7-D0和D15-D8中的任一组。

　

　

参数

　

名称

 类型 范围

默认值

<digital>

离散型 D0至D15

D0

<group>

离散型

GROup1至GROup4

----

<pod>

离散型

{POD1|POD2}

----

<state>

布尔型 {{0|OFF}|{1|ON}}

0|OFF

注：POD1代表D0-D7，POD2代表D15-D8。
　


说明


只有包含数字通道的组才可以选择。

您可以使用:LA:GROup<n>:APPend命令为4个自定义组Group1至Group4添加数字通道。

同一数字通道只能属于一个组，不可以重复分组。
每组最多包含16个数字通道。


　

返回格式

　

查询返回1或0。

　

　

举例

　

下面的命令关闭D5。

 :LA:DISPlay D5 OFF 

下面的查询返回0。

 :LA:DISPlay? D5
