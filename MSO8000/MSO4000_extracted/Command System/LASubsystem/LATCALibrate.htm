:LA:TCALibrate

　

　

命令格式

　

:LA:TCALibrate <tcal>
 :LA:TCALibrate?


　

功能描述

　

设置延迟校正时间。

　

　

参数

　

名称

 类型 范围

默认值

<tcal>

实型 100 ns至-100 ns

0 s



说明


使用示波器进行实际测量时，探头电缆的传输延迟可能带来较大的误差（零点偏移）。MSO4000/DS4000支持用户设定一个延迟时间以校正对应通道的零点偏移。零点偏移定义为波形与阈值电平线的交点相对于触发位置的偏移量。

　

　

返回格式

　

查询以科学计数的形式返回延迟校正时间。

　

　

举例

　

下面的命令设置延迟校正时间为10 ns。

 :LA:TCALibrate 0.00000001
下面的查询返回1.000000e-08。

 :LA:TCALibrate?
