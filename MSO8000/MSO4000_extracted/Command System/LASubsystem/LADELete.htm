:LA:DELete

　

　

命令格式

　

:LA:DELete <digital>|<group>


　

功能描述

　

取消16个 数字通道中任一通道的分组设置，或者取消Group1-Group4中的任一组通道的分组设置。

　

　

参数

　

名称

 类型 范围

默认值

<digital>

离散型

D0 至 D15

----

<group>

离散型

GROup1 至 GROup4

----



说明


该命令仅适用于已分组的通道或包含通道的组。
您可以使用:LA:GROup<n>:APPend命令为4个自定义组添加数字通道，同一数字通道只能属于一个组，不可以重复分组。

　

　

举例

　

下面的命令取消D3的分组设置。

 :LA:DELete D3
