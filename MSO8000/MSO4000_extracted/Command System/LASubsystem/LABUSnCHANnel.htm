:LA:BUS<n>:CHANnel

　

　

命令格式

　

:LA:BUS<n>:CHANnel <channel>

:LA:BUS<n>:CHANnel?

　

功能描述

　

设置数字总线BUS1或BUS2对应的通道组，可以选择D7-D0、D15-D8和D15-D0。

　

　

参数

　

名称

 类型 范围

默认值

<n>

离散型 {1|2}

BUS1

<channel>

离散型 {L|H|HL}

----



说明

L：D7-D0；
H：D15-D8；
HL：D15-D0。

　

　

返回格式

　

查询返回L、H或HL。


　

举例

　

下面的命令设置数字总线BUS2对应的通道组为D15-D0。

 :LA:BUS2:CHANnel1 HL
下面的查询返回HL。

 :LA:BUS2:CHANnel?
