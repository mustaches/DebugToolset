:LA:GROup<n>:APPend

　

　

命令格式

　

:LA:GROup<n>:APPend <digital>,[< digital>,< digital>...]


　

功能描述

　

为4个自定义组Group1至Group4添加 数字通道。

　

　

参数

　

名称

 类型 范围

默认值

<digital>

离散型 D0至D15

----

<n>

离散型

{1|2|3|4}

----

　


说明


同一通道只能属于一个组，不可以重复分组。
每组最多包含16个数字通道。


　

举例

 下面的命令为Group1添加D0、D2、D5三个数字通道。

 :LA:GROup1:APPend D0,D2,D5
