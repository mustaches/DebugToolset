:REFerence:COLor

　

　

命令格式

　

:REFerence:COLor <color>
:REFerence:COLor?


　

功能描述

　

为当前通道的参考波形指定一个颜色。您可以使用:REFerence<n>:CURRent命令选择当前通道。

　

　

参数

　

名称

 类型 范围

默认值

<source>

离散型

 {GRAY|GREEN|DARKGREEN|MAGENTA|ORANGE}

GRAY

　

 

返回格式

　

查询返回GRAY、GREEN、DARKGREEN、MAGENTA或ORANGE。

　

　

举例

　

下面的命令将当前通道参考波形的颜色设置为草绿。


 :REFerence:COLor GREEN

下面的查询返回GREEN。

 :REFerence:COLor?
