:REFerence:VSCale

　

　

命令格式

　

:REFerence:VSCale <vscale>
:REFerence:VSCale?


　

功能描述

　

调节当前通道的参考波形的垂直档位。

　

　

参数

　

名称

 类型 范围

默认值

<vscale>

整型

1至10

Null

 

 

说明

参考波形占屏幕的网格数（N1）取决于原波形所占的网格数（N）和参考波形的垂直档位（X），N1=N*2（X-5）。默认时，垂直档位为5，参考波形的大小等于原波形的大小。

　

　

返回格式

　

查询返回一个整数。

　

　

举例

　

下面的命令设置当前通道的参考波形的垂直档位为1。

 :REFerence:VSCALe 1

下面的查询返回1。

 :REFerence:VSCALe?
