:REFerence:SOURce

　

　

命令格式

　

:REFerence:SOURce <source>
:REFerence:SOURce?


　

功能描述

　

为当前通道指定一个参考源。您可以使用:REFerence<n>:CURRent命令选择当前通道。

　

　

参数

　

名称

 类型 范围

默认值

<source>

离散型

{CHANnel1|CHANnel2|CHANnel3|CHANnel4|MATH|D<m>}

CHANnel1

　

　

说明

　

只能选择当前已打开的通道作为当前通道的参考源。

　

 

返回格式

　

查询返回CHAN1、CHAN2、CHAN3、CHAN4、MATH或D0-D15。

　

　

举例

　

下面的命令选择CHANnel2作为当前通道的参考源。

 :REFerence:SOURce CHANnel2

下面的查询返回CHAN2。

 :REFerence:SOURce?
