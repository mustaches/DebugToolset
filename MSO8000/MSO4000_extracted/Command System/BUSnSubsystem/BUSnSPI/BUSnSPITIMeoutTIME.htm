:BUS<n>:SPI:TIMeout:TIME

 

 

命令格式

 

:BUS<n>:SPI:TIMeout:TIME <time>
:BUS<n>:SPI:TIMeout:TIME?


 

功能描述

 

当解码模式（:BUS<n>:SPI:MODE命令）选择超时后，设置超时时间。

 

 

参数

 

名称

 类型 范围

默认值

<n>

 离散型

{1|2}

----

<time>

 实型

100ns至1s

1μs


 

返回格式

 

查询以科学计数形式返回所设的超时时间。

 

 

举例

 

下面的命令设置超时时间为 200ms。

 :BUS1:SPI:TIMeout:TIME 0.2

下面的查询返回2.000000e-01。

 :BUS1:SPI:TIMeout:TIME?
