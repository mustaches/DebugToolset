:BUS<n>:SPI:MODE 

　

　

命令格式

　

:BUS<n>:SPI:MODE <endian>
:BUS<n>:SPI:MODE?


　

功能描述

　

选择总线1或2上SPI解码时 的解码模式。

　

　

参数

　

名称

 类型 范围

默认值

<n>

 离散型

{1|2}

----

<endian>

离散型

{CS|TIMeout}

TIMeout

　

 

说明

 CS：设置在片选通道（CS）为“高”或“低”时触发。
TIMeout：设置在示波器开始搜索要在其上触发的数据（SDA）前，时钟（SCL）信号必须为空闲状态的最小时间。可以使用:BUS<n>:SPI:TIMeout:TIME命令设置超时时间，范围为100ns至1s。

该命令仅适用于4通道的示波器。

　

　

返回格式

　

查询返回CS或TIM。

　

　

举例

　

下面的命令选择CS。
:BUS1:SPI:MODE CS

下面的查询返回CS。

 :BUS1:SPI:MODE?
