:BUS<n>:SPI:ENDian 

　

　

命令格式

　

:BUS<n>:SPI:ENDian <endian>
:BUS<n>:SPI:ENDian?


　

功能描述

　

选择总线1或2上SPI解码时数据传输的位序。

　

　

参数

　

名称

 类型 范围

默认值

<n>

 离散型

{1|2}

----

<endian>

离散型

{MSB|LSB}

MSB

　

 

返回格式

　

查询返回MSB或LSB。

　

　

举例

　

下面的命令选择MSB。
:BUS1:SPI:ENDian MSB

下面的查询返回MSB。

:BUS1:SPI:ENDian?
