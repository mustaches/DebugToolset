:BUS<n>:SPI:MISO:THReshold

　

　

命令格式

　

:BUS<n>:SPI:MISO:THReshold <thre>
:BUS<n>:SPI:MISO:THReshold?


　

功能描述

　

设置总线1或2上SPI解码的MISO数据通道阈值。

　

　

参数

　

名称

 类型 范围

默认值
<n> 离散型 {1|2} ----
<thre> 实型 屏幕中心的 ± 4 × VerticalScale 0

注：对于VerticalScale，参考:CHANnel<n>:SCALe命令。



说明

当MISO通道选择关闭时，阈值不能设置，但是仍然可以查询当前MISO通道的阈值。


　

返回格式

　

查询以科学计数形式返回所设的阈值。

　

　

举例

　

下面的命令设置阈值为2.4 V。

 :BUS1:SPI:MISO:THReshold 2.4

下面的查询返回2.400000e+00。

 :BUS1:SPI:MISO:THReshold?
