:BUS<n>:RS232:DBITs 

　

　

命令格式

　

:BUS<n>:RS232:DBITs <bits>
:BUS<n>:RS232:DBITs?


　

功能描述

　

选择RS232解码时每帧数据的宽度。

　

　

参数

　

名称

 类型 范围

默认值
<n> 离散型 {1|2} ----
<bits> 离散型

{5|6|7|8|9}

 8

　

 

返回格式

　

查询返回5、6、7、8、或9。

　

　

举例

　

下面的命令选择数据宽度为7。
:BUS1:RS232:DBITs 7

下面的查询返回7。

:BUS1:RS232:DBITs?
