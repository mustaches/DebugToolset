:BUS<n>:RS232:PACKet 

　

　

命令格式

　

:BUS<n>:RS232:PACKet <bool>
:BUS<n>:RS232:PACKet?


　

功能描述

　

启用或禁用数据传输时的包停止符。启用包停止符时，会根据包结束符将若干个数据块合并。

　

　

参数

　

名称

 类型 范围

默认值
<n> 离散型 {1|2} ----
<bool> 布尔型 {{0|OFF}|{1|ON}} 0|OFF

　

 

返回格式

　

查询返回0或1。

　

　

举例

　

下面的命令启用包停止符。

 :BUS1:RS232:PACKet ON  或  :BUS1:RS232:PACKet 1

下面的查询返回1。

 :BUS1:RS232:PACKet?
