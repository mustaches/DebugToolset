:BUS<n>:FLEXray:SOURce

　

　

命令格式

　

:BUS<n>:FLEXray:SOURce <sour>
:BUS<n>:FLEXray:SOURce?


　

功能描述

　

选择总线1或2上FlexRay解码时的解码源。

　

　

参数

　

名称

 类型 范围

默认值
<n> 离散型 {1|2} ----
<sour> 离散型 {CHANnel1|CHANnel2|CHANnel3|CHANnel4|D<m> } CHANnel1
<m> 整型 0至15 ----

　

 

返回格式

　

查询返回CHAN1、CHAN2、CHAN3、CHAN4或D0-D15。

　

　

举例

　

下面的命令设置通道2为解码源。


 :BUS1:FLEXray:SOURce CHANnel2

下面的查询返回CHAN2。


 :BUS1:FLEXray:SOURce?
