:BUS<n>:IIC:OFFSet

　

　

命令格式

　

:BUS<n>:IIC:OFFSet <val>
:BUS<n>:IIC:OFFSet?


　

功能描述

　

设置总线1或2上IIC解码时显示的垂直偏移。

　

　

参数

　

名称

 类型 范围

默认值
<n> 离散型 {1|2} ----

<val>

整型

普通1：-166至148

统计2：-163至143

半屏3：-103至52

0

注1：指屏幕正常显示且统计功能（参考:MEASure:STATistic:DISPlay命令）未打开。
注2：指屏幕正常显示但统计 功能（参考:MEASure:STATistic:DISPlay命令）已打开。
注3：指屏幕被分成两个窗口显示（参考:TIMebase:DELay:ENABle和:CALCulate:FFT:SPLit命令）。

　

　

返回格式

　

查询以整数形式返回偏移值。

　

　

举例

　

下面的命令设置垂直偏移为 2。
:BUS1:IIC:OFFSet 2

下面的查询返回2。

 :BUS1:IIC:OFFSet?
