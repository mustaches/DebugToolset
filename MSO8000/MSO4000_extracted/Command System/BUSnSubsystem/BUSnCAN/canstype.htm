:BUS<n>:CAN:STYPe 

　

　

命令格式

　

:BUS<n>:CAN:STYPe <stype>
:BUS<n>:CAN:STYPe?


　

功能描述

　

设置总线1或2上CAN解码的信号类型。

　

　

参数

　

名称

 类型 范围

默认值
<n> 离散型 {1|2} ----
<stype> 离散型 {CANH|CANL|DIFFerential } CANH

　

 

返回格式

　

查询返回CANH、CANL或DIFF。

　

　

举例

下面的命令设置的信号类型是CAN_L。
:BUS1:CAN:STYPe CANL

下面的查询返回CANL。

 :BUS1:CAN:STYPe?
