:BUS<n>:CAN:BAUD 

　

　

命令格式

　

:BUS<n>:CAN:BAUD <baud>
:BUS<n>:CAN:BAUD?


　

功能描述

　

选择CAN解码时的信号速率。

　

　

参数

　

名称

 类型 范围

默认值
<n> 离散型 {1|2} ----
<baud> 离散型 {100000|125000|250000|400000|500000|800000|1000000|USER} 500000

　

 

返回格式

　

查询返回当前所选的信号速率的值，单位为b/s。例如，100000。

　

　

举例

　

下面的命令设置信号速率为100000。

 :BUS1:CAN:BAUD 100000

下面的查询返回100000。

 :BUS1:CAN:BAUD?
