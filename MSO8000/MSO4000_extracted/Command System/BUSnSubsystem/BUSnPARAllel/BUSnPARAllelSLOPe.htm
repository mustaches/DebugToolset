:BUS<n>:PARallel:SLOPe 

　

　

命令格式

　

:BUS<n>:PARallel:SLOPe <pos>
:BUS<n>:PARallel:SLOPe?


　

功能描述

　

选择在时钟的上升沿、下降沿或上下沿对通道数据进行采样。

　

　

参数

　

名称

类型

范围

默认值

<n>

离散型

{1|2}

----

<pos>

离散型

{POSitive|NEGative|BOTH}

POSitive

　

 

说明

　

当前没有设置时钟通道时（:BUS<n>:PARallel:CLK），数据采集发生在通道数据发生跳变时，由该命令设置的边沿可忽略。

　

　

返回格式

　

查询返回POS、NEG或BOTH。

　

　

举例

　

下面的命令选择下降沿。

:BUS1:PARallel:SLOPe NEGative

下面的查询返回NEG。

:BUS1:PARallel:SLOPe?
