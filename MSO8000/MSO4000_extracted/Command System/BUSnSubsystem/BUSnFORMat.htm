:BUS<n>:FORMat

　

　

命令格式

　

:BUS<n>:FORMat <format>
:BUS<n>:FORMat?


　

功能描述

　

设置总线1或2的显示格式为：十六进制、十进制、二进制或ASCII。

　

　

参数

　

名称

 类型 范围

默认值

<n>

 离散型

{1|2}

----

<format>

离散型

{HEX|DEC|BIN|ASCii}

HEX

　

 

返回格式

　

查询返回HEX、DEC、BIN或ASC。

　

　

举例

　

下面的命令设置总线1的显示格式为十进制。
:BUS1:FORMat DEC

下面的查询返回DEC。

:BUS1:FORMat?
