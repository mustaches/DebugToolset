:CALCulate:ADVanced:VARiable2

　

　

命令格式

　

:CALCulate:ADVanced:VARiable2 <numeric_value>
:CALCulate:ADVanced:VARiable2?


　

功能描述

　

设置高级运算表达式中的变量2。该命令决定了:CALCulate:ADVanced:EXPRession命令可能引用的变量2的值。

　

　

参数

　

名称

 类型 范围

默认值

<numeric_value>

 实型

-9.9999e-09至9.9999e+09

0

　

 

返回格式

　

查询以科学计数形式返回当前变量2的值。

　

　

举例

　

下面的命令设置变量2的值为606。

 :CALCulate:ADVanced:VARiable2 606

下面的查询返回6.060000e+02。

 :CALCulate:ADVanced:VARiable2?
