:CALCulate:LOGic:BTHReshold

　

　

命令格式

　

:CALCulate:LOGic:BTHReshold <thre>
:CALCulate:LOGic:BTHReshold?


　

功能描述

　

设置逻辑通道B的门限。注意，逻辑通道的门限和模拟通道的不同。

　

　

参数

　

名称

 类型 范围

默认值
<thre> 实型 屏幕范围（偏移随着档位的变化而变化） 0

　

 

返回格式

　

查询以科学计数形式返回偏移值。

　

　

举例

　

下面的命令设置逻辑通道B的门限为2。

 :CALCulate:LOGic:BTHReshold 2

下面的查询返回2.000000e+00。

 :CALCulate:LOGic:BTHReshold?
