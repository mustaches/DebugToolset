:CALCulate:LOGic:SA 

　

　

命令格式

　

:CALCulate:LOGic:SA <source>
:CALCulate:LOGic:SA?


　

功能描述

　

选择逻辑运算时信源A的通道源。

　

　

参数

　

名称

类型

范围

默认值

<source>

离散型

{CHANnel1|CHANnel2|CHANnel3|CHANnel4 }

CHANnel1

　

 

返回格式

　

查询返回CHAN1、CHAN2、CHAN3或CHAN4。

　

　

说明

　

如果当前的逻辑运算类型为NOT，则使用该命令指定的信源，不使用:CALCulate:LOGic:SB命令指定的信源。

　

　

举例

　

下面的命令选择通道2作为信源A的通道源。

 :CALCulate:LOGic:SA CHANnel2

下面的查询返回CHAN2。

 :CALCulate:LOGic:SA?
