:CALCulate:ADD:VSCale 

　

　

命令格式

　

:CALCulate:ADD:VSCale <scale>
:CALCulate:ADD:VSCale?


　

功能描述

　

设置加法运算结果的垂直档位。

　

　

参数

　

名称

 类型 范围

默认值

<scale>

 实型

与当前的运算类型、通道档位 相关

2

注：对于通道档位，参考:CHANnel<n>:SCALe命令。

　

 

返回格式

　

查询以科学计数形式返回档位值。

　

　

举例

　

下面的命令设置加法运算结果的垂直档位为2。

 :CALCulate:ADD:VSCale 2

下面的查询返回2.000000e+00。

 :CALCulate:ADD:VSCale?
