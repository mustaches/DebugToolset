:CALCulate:FFT:HSPan

　

　

命令格式

　

:CALCulate:FFT:HSPan <span>
:CALCulate:FFT:HSPan?


　

功能描述

　

设置FFT运算结果每div的频率值。

　

　

参数

　

名称

类型

范围

默认值

<span>

实型

屏幕当前的FFT采样率/200 至  屏幕采当前的FFT采样率/20

1.25 MHz

注：
在取值范围内以1X、2X、5X和10X步进。
屏幕当前的FFT采样率=水平每格点数/水平时基。对于水平水平时基，请参考:TIMebase[:MAIN]:SCALe命令。
　

　

 

返回格式

　

查询以科学计数形式返回频率值。单位为Hz/div。

　

　

举例

　

下面的命令设置FFT运算结果每div的频率值 为2.5 MHz。

 :CALCulate:FFT:HSPan 2500000

下面的查询返回2.500000e+06。

 :CALCulate:FFT:HSPan?
