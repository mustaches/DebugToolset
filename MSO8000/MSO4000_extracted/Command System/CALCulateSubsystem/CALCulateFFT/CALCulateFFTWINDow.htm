:CALCulate:FFT:WINDow 

　

　

命令格式

　

:CALCulate:FFT:WINDow <window>
:CALCulate:FFT:WINDow?


　

功能描述

　

选择FFT运算的窗函数。

　

　

参数

　

名称

 类型 范围

默认值

<window>

离散型

{RECTangle|HANNing|HAMMing|BLACkman}

RECTangle

　

 

返回格式

　

查询返回RECT、HANN、HAMM或BLAC。

　

　

举例

　

下面的命令选择HANNing窗函数。

 :CALCulate:FFT:WINDow HANNing

下面的查询返回HANN。

 :CALCulate:FFT:WINDow?
