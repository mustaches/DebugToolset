:CALCulate:FFT:HOFFset

　

　

命令格式

　

:CALCulate:FFT:HOFFset <offs>
:CALCulate:FFT:HOFFset?


　

功能描述

　

设置FFT运算结果的水平偏移。单位为Hz。

　

　

参数

　

名称

类型

范围

默认值

<offs>

实型

-0.4*屏幕当前的FFT采样率 至  +0.4*屏幕当前的FFT采样率

0

注：屏幕 当前的FFT采样率=水平每格点数/水平时基。对于水平水平时基，请参考:TIMebase[:MAIN]:SCALe命令。
　

 

返回格式

　

查询以科学计数形式返回水平偏移值。

　

　

举例

　

下面的命令设置FFT运算结果的水平偏移为10 MHz。

 :CALCulate:FFT:HOFFset 10000000

下面的查询返回1.000000e+07。

 :CALCulate:FFT:HOFFset?
