:CALCulate:FFT:HSCale 

　

　

命令格式

　

:CALCulate:FFT:HSCale <hscale>
:CALCulate:FFT:HSCale?


　

功能描述

　

设置FFT运算时的水平系数，该命令间接设置FFT的水平刻度。

　

　

参数

　

名称

 类型 范围

默认值

<hscale>

离散型

{1|2|3|4}

2



说明

1：水平刻度=屏幕当前的FFT采样率/20。
2：水平刻度=屏幕当前的FFT采样率/40。
3：水平刻度=屏幕当前的FFT采样率/100。
4：水平刻度=屏幕当前的FFT采样率/200。

 

　

返回格式

　

查询返回1、2、3或4。

　

　

举例

　

下面的命令设置水平系数为2。

 :CALCulate:FFT:HSCale 2

下面的查询返回2。

 :CALCulate:FFT:HSCale?
