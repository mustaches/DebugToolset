:CURSor:TRACk:SOURce1

　

　

命令格式

　

:CURSor:TRACk:SOURce1 <source>
:CURSor:TRACk:SOURce1?


　

功能描述

　

设置光标追踪测量时，光标A测量的通道源。

　

　

参数

　

名称

 类型 范围

默认值

<source>

 离散型

{CHANnel1|CHANnel2|CHANnel3|CHANnel4|MATH|NONE}

CHANnel1

注：只能选择已打开的通道作为测量源。

　

　

 

说明

　

CHANnel1-CHANnel4：选择通道1至通道4中的任意通道作为光标A的测量源。

MATH：选择数学运算通道中的波形作为光标A的测量源。

NONE：不使用光标A。

　

　

返回格式

　

查询返回CHAN1、CHAN2、CHAN3、CHAN4、MATH或NONE。

　

　

举例

　

下面的命令设置通道2为测量源。


 :CURSor:TRACk:SOURce1 CHANnel2

下面的查询返回CHAN2。


:CURSor:TRACk:SOURce1?
