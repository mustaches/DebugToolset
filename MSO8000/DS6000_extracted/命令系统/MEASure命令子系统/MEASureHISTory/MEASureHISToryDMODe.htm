:MEASure:HISTory:DMODe

　

　

命令格式

　

:MEASure:HISTory:DMODe <mod>
:MEASure:HISTory:DMODe?


　

功能描述

　

设置历史测量数据的显示形式。

注意，使用该命令之前需打开测量历史（:MEASure:HISTory:DISPlay命令）。

　

　

参数

　

名称

 类型 范围

默认值

<mod>

 离散型

{TABLe|GRAPh}

GRAPh

　

 

说明

　

TABLe：以表格形式显示最后打开的最多5个测量项的最近10次测量结果。

GRAPh： 以图形形式显示最后打开的最多5个测量项的最近10次测量结果。各测量点用线性插值方式连接起来。

　

　

返回格式

　

查询返回“TABL”或“GRAP”。

　

　

举例

　

下面的命令选择表格显示。


 :MEASure:HISTory:DMODe TABLe

下面的查询返回“TABL”。

　

:MEASure:HISTory:DMODe?
