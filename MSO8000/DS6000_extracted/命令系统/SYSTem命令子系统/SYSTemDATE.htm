:SYSTem:DATE

　

　

命令格式

　

:SYSTem:DATE <year>,<month>,<day>
:SYSTem:DATE?


　

功能描述

　

设置系统日期。

　

　

参数

　

名称

 类型 范围

默认值
<year> 整型 2000至2099 ----
<month> 整型 01至12 ----

<day>

 整型

01至31

----

　

 

返回格式

　

查询以字符串形式返回当前的日期。

　

　

举例

　

下面的命令设置系统日期为2010年9月17日。


 :SYSTem:DATE 2010,9,17   或   :SYSTem:DATE 2010,09,17

下面的查询返回“2010, 9,17”。


:SYSTem:DATE?
