:SYSTem:TIME

　

　

命令格式

　

:SYSTem:TIME <hours>,<minutes>,<seconds>
:SYSTem:TIME?


　

功能描述

　

设置系统时间。

　

　

参数

　

名称

 类型 范围

默认值
<hours> 整型 0至23 ----
<minutes> 整型 0至59 ----

<seconds>

 整型

0至59

----

　

 

返回格式

　

查询以字符串形式返回当前的时间。注意，由于存在命令响应等因素，返回值相对于设定值有一定的延时。

　

　

举例

　

下面的命令设置系统时间为：16点05分15秒。


 :SYSTem:TIME 16,05,15   或   :SYSTem:TIME 16,5,15

下面的查询返回当前的时间，例如：16, 5,18。


:SYSTem:TIME?
