:FUNCtion:WREPlay:MODE

　

　

命令格式

　

:FUNCtion:WREPlay:MODE <mode>
:FUNCtion:WREPlay:MODE?


　

功能描述

　

设置波形回放的模式。

　

　

参数

　

名称

 类型 范围

默认值

<mode>

 离散型

{REPeat|SINGle}

SINGle

　

 

说明

　

REPeat：循环回放，从起始帧回放到终止帧后，再重复回放直至停止回放。

SINGle：单次回放，从起始帧回放到终止帧后停止。
　

　

返回格式

　

查询返回“REP”或“SING”。

　

　

举例

　

下面的命令选择循环回放。


 :FUNCtion:WREPlay:MODE REPeat


下面的查询返回“REP”。


 :FUNCtion:WREPlay:MODE?
