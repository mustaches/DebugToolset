# ANSI 转义序列颜色规则 (ANSI Escape Codes)

终端文本颜色的显示通常依赖于 ANSI 转义序列，其基本格式为：
`\x1b[<参数>m` 或 `\033[<参数>m`

参数通常由分号分隔的数字组成，控制文字的样式、前景色和背景色。
在遇到 `\x1b[0m` 时，所有属性重置为默认值。

## 常用控制码
0 : 重置所有属性
1 : 高亮 / 粗体
2 : 弱化 (Dim)
3 : 斜体
4 : 下划线
7 : 反转前背景色

## 前景色 (Foreground Colors)
30 : 黑色 (Black)
31 : 红色 (Red)
32 : 绿色 (Green)
33 : 黄色 (Yellow)
34 : 蓝色 (Blue)
35 : 品红/洋红 (Magenta)
36 : 青色 (Cyan)
37 : 白色 (White)

## 背景色 (Background Colors)
40 : 黑色
41 : 红色
42 : 绿色
43 : 黄色
44 : 蓝色
45 : 品红
46 : 青色
47 : 白色

## 亮色系列 (前景色: 90-97, 背景色: 100-107)
90 : 亮黑色 (灰)
91 : 亮红色
92 : 亮绿色
93 : 亮黄色
94 : 亮蓝色
95 : 亮品红
96 : 亮青色
97 : 亮白色

## 解析示例
`\x1b[31mError:\x1b[0m File not found`
解析结果：将 "Error:" 渲染为红色，之后的 " File not found" 渲染为默认颜色。

`\x1b[1;32mSuccess\x1b[0m`
解析结果：将 "Success" 渲染为高亮/粗体的绿色。

## 进阶：256色和RGB色 (在本项目中暂做可选实现)
256色: `\x1b[38;5;<n>m`
RGB真彩: `\x1b[38;2;<r>;<g>;<b>m`
